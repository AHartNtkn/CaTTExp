# Cones over coherence terms in CaTT (N^cone), round 5

*A self-contained problem. No knowledge of the project that posed it is assumed. Everything listed under "What is known" is proved and is not re-asked. Questions are at the end, smallest first.*

## Background

**CaTT.** Contexts list variables `x : A`, where a type is `⋆` or `a →_A b` with a, b terms of type A. Terms are variables or `coh_{Q,B}[γ]`, where Q is a *pasting context* (a context presenting a globular pasting diagram), B is a type over Q satisfying the usual side conditions (either both boundary terms are full in Q, the *coherence case*, or each is full in the matching boundary of Q, the *composition case*), and `γ : Δ ⊢ Q` is a substitution. Reference: Finster–Mimram, *A type-theoretical definition of weak ω-categories* (LICS 2017); Benjamin–Finster–Mimram, *Globular weak ω-categories as models of a type theory* (2021). Composition order below is diagrammatic, and `u ∗_k w` denotes the binary composite along a k-cell, which is itself a composition coherence over two disks glued along a k-disk. For a term t of dimension m ≥ 1 write `σt, τt` for its source and target, and `σʲt` for the iterated source.

**Cone over a globular context.** Call a context *globular* if every variable's type is `⋆` or `a → b` with a, b variables; every pasting context is globular. For globular Γ, the *specified cone* `Cone(Γ; c)` extends Γ by an object `c : ⋆` and one variable `p_t` for each variable t of Γ, in order:

```
p_x : c → x                                                   (dim x = 0)
p_t : p_{τt}  →  p_{σt} ∗_{m−1} (p_{σ²t} ∗_{m−2} ( … (p_{σᵐt} ∗₀ t)))      (dim t = m ≥ 1)
```

So `f : x → y` gets `p_f : p_y ⇒ p_x ∗₀ f`, and `α : f ⇒ g` gets `p_α : p_g ⇛ p_f ∗₁ (p_x ∗₀ α)`. This is a well-formed context for every globular Γ (by induction on the variables: each composite in the target is well formed because the projections of the boundary variables already have the matching types). It is the cone of T. J. Mikhail's Thm 3.3 (*A type-theoretic definition of lax (∞,∞)-limits*, arXiv 2412.13310), lax at the vertices. When Γ is a pasting context, the strict ω-category freely generated by `Cone(Γ; c)` is the Ara–Maltsiniotis join `c ⋆ Γ`, with `p_t ↦ c ⋆ t`.

**Cones over arbitrary contexts.** In a general context a variable may have composite boundaries, e.g. `τ : f ∗₀ g ⇒ h`. The cone variable over τ then needs a cone cell `P(f ∗₀ g)` over the *term* `f ∗₀ g`. Extend p from variables to all terms:

```
P(x)              := p_x
P(coh_{Q,B}[γ])   := Π(Q, B)[Cone(γ)]
```

where `Cone(γ) : Cone(Γ; c) ⊢ Cone(Q; c)` sends `q ↦ γ(q)`, `c ↦ c`, `p_q ↦ P(γ(q))`, and `Π(Q, B)` is a chosen term of `Cone(Q; c)`. For a term t of dimension m ≥ 1 put

```
T(t) := P(σt) ∗_{m−1} (P(σ²t) ∗_{m−2} ( … (P(σᵐt) ∗₀ t))).
```

For `c₀ := coh_{Q,B}[id_Q]`, of dimension n, the term `Π(Q, B)` must have type

```
Π(Q, B) : P(τc₀) → T(c₀)          (an (n+1)-term of Cone(Q; c)).
```

This type is well formed once P is defined on the boundary terms of c₀, which have dimension < n. So the definition is a recursion on dimension. Within a dimension, the boundary terms of an n-coherence may themselves contain n-dimensional subterms only in the composition case, through lower-dimensional factors, so the recursion is well founded with the order "lower dimension first, then structural" .

## Statement

> **Conjecture N^cone.** For every pasting context Q and every type B such that `coh_{Q,B}` is a valid coherence, there is a term `Π(Q, B)` of `Cone(Q; c)` of type `P(τc₀) → T(c₀)`, where P on the boundary of c₀ is defined from Π at lower dimensions as above. Moreover Π can be chosen so that, in the free strict ω-category on `Cone(Q; c)`, `π(Π(Q, B)) = c ⋆ π(c₀)` (the join of c with the strict image of c₀).

The strict-image clause is part of the statement because the inductive step uses it: it guarantees that `P(u)` has strict image `c ⋆ π(u)` for every term u.

Consequence: for every CaTT context Γ, the extension `Cone(Γ; c)` (with P in place of p in the types of the cone variables) is a well-formed context. This is a precise form of Mikhail's Conjecture 3.6 ("cones exist over arbitrary contexts"), restricted to a specified construction.

## What is known

1. **Dimension 1 (proved).** For the composite of a chain `x₀ —f₁→ … —f_m→ x_m`, Π is the vertical composite of the whiskered cone generators `p_{f_m}`, `p_{f_{m−1}} ∗₀ f_m`, … followed by the associator coherence κ over `c → x₀ → … → x_m`.

2. **Every relative-coherence witness in a join context strictifies to an identity.** The free strict ω-category on `Cone(Q; c)` is the join `c ⋆ Q`, which is ν(K) for a strong Steiner complex K (Ara–Maltsiniotis, *Joint et tranches*). In a strong Steiner complex every positive cycle is zero, so every endo-cell of c ⋆ Q is an identity.

3. **Reduction to relative coherence.** Write **RC(r) for Δ** for the statement: any two parallel r-terms of Δ with equal strict images are connected by an (r+1)-term.
   - If RC(1), …, RC(n) hold for `Cone(Q; c)` for every pasting context Q, then N^cone holds through dimension n, in both the coherence and the composition case. (Lift strict cells to terms, then correct faces one dimension at a time with RC witnesses; the strict image is unchanged.)

4. **Fixed dimension suffices.** For the standard recursively defined binary compositions, a syntactic *cut translation* D lowers the dimension of terms crossing a chosen 0/1 colouring of the 0-variables, with D(Σt) ≡ t, D(e ∗₀ u) ≡ D(u), D(u ∗_k v) ≡ D(u) ∗_{k−1} D(v), and D(t[θ]) ≡ D(t)[D(θ)]. With the substitution `e_Q : Cone(ΣQ; d) ⊢ Cone(Q; c)` (U ↦ d, V ↦ S, Σc ↦ p_S, Σq ↦ p_N ∗₀ q̄, Σp_q ↦ p_{q̄}) it gives a literal retraction D(L_Q t) ≡ t, hence

   ```
   RC(r+1, Cone(ΣQ; d))  ⇒  RC(r, Cone(Q; c)),
   [∀Q RC(n, Cone(Q; c))]  ⇒  [∀Q ∀ r < n RC(r, Cone(Q; c))]  ⇒  N^cone through dimension n.
   ```

5. **Dimension 2 holds.** RC(1) and RC(2) hold in every CaTT context, so N^cone holds in dimension 2. There is also an explicit term for `α ∗₀ β`.

6. **The first 3-dimensional instance.** With generic schemes for P(1_f) and P(α ∗₁ β) over D¹ and D² ∗₁ D², the unitor `c₀ : α ⇛ α ∗₁ 1_g` over D² has an explicit 4-term `P(α ∗₁ 1_g) → P(α) ∗₂ (p_f ∗₁ (p_x ∗₀ c₀))`, a chain of ten 4-cells built from six auxiliary coherences over pasting contexts, with strict image `1_{p_α} = c ⋆ π(c₀)`. It works for every coherence c₀ of that type.

7. **Where the lax-square argument stops.** RC(3) holds on the lax square (x⁻, x⁺, y⁻, y⁺; x↑, y↑, f⁻, f⁺; F : f⁻ ∗₀ y↑ ⇒ x↑ ∗₀ f⁺): for a 2-term with strict image F, exactly one 0-column of its arity carries F, the others are point-supported and factor literally through point contexts, and this factorisation is stable under substitution. It gives normalisers compatible with every 3-term. In `c ⋆ Q` the apex c is the unique 0-source and the last vertex x_k of Q is the unique 0-sink, but a term like `p_x ∗₀ α` has a discarded column carrying the nonidentity edge `p_x : c → x`, so the point-support step fails.

8. **A tool that handles one fixed edge.** On the cylinder of a composable pair (x → y → z), a column that carries a lax square but does not span the unique source and sink factors literally through a retained pasting context `C_n ∗₀ D¹(h)` or `D¹(h) ∗₀ C_n` (C_n a vertical n-chain, D¹(h) one edge), where every relevant substitution sends h to the **same edge variable**. With fixed-whiskering 3-cells, path comparisons after whiskering, a compatibility cell φ^h with the vertical fold, and evaluation fusion, this gives normalisers and RC(3) for that cylinder.

9. **Strict case.** In strict ω-categories `c ⋆ −` is functorial on cells, so the strict analogue of N^cone holds in every dimension.

10. **Loop-freeness is needed.** In (x, a : 1_x → 1_x) the weak free object groupoidifies to S² and the strict one to K(ℤ, 2), so RC(3) fails there.

11. **The support lemma.** For every CaTT context Γ and term t, the generators used by the strict image of t form exactly the dependency-closed set of variables of t:
    ```
    supp_{πΓ}(πt) = supp_Γ(t).
    ```
    Strict support is invariant under the strict axioms. The proof is by induction on derivations: a composition head goes to the total composite, and a coherence head goes to 1_{πs} with s full.

    *Consequence.* A term whose strict image is supported in a dependency-closed sub-context S is literally a term of S. So parallel terms with strict image 1_w are joined by one full coherence over supp(w). Also, a point-supported column of an arity factors literally through a point, by renaming that point.
12. **RC(3) for Cone(D²; c).** Write a = p_x, b = p_y, u = p_f : b ⇒ a∗₀f, v = p_g : b ⇒ a∗₀g, w = a∗₀α, d = u∗₁w, M = p_α : v ⇛ d, and K = Cone(D²; c) without M.
    - *Strict cells.* The nonidentity strict 2-cells are α, u, v, w and d. The only nonidentity strict 3-cell is M, which has no whiskers and does not compose with itself.
    - *RC(3, K).* Each 2-term with strict image u, v or d has exactly one active column, a vertical chain C_n, while its other columns are point-supported. Normalisers N_A : A ⇛ ê_{p,q} keep the literal 1-boundaries. They come from a generic comparison χ_r over C_n followed by an evaluation E(σ; B) that is the same for every full r : B.
    - *Fusion.* A fusion lemma, proved by induction on the formal term with only depth-1 naturality, gives N_T ∗₂ N_B ≃ N_A for every 3-term T.
    - *Adjoining M.* Every U with πU = M satisfies 𝒯(U) ≃ A_U ∗₂ M ∗₂ B_U, with A_U and B_U in K. Level-1 whiskers are removed by depth-1 naturality and level-0 whiskers by one coherence over the 3-disc. RC(3, K) then compares the prefixes and suffixes.
    - *What it uses.*
      - Every 2-cell involving u or v spans c → y.
      - The other non-point whisker a∗₀α has a pasting context as its support.
      - The nonidentity vertical word is one of u, v, w, or u followed by w.
      - M has no whiskers.

13. **RC(3) for every vertical chain of 2-disks (proved).** Let Q_m = (x, y, f_0, …, f_m : x → y, α_i : f_{i−1} ⇒ f_i). Write a = p_x, b = p_y, F_i = a ∗₀ f_i, A_i = a ∗₀ α_i, u_i = p_{f_i} : b ⇒ F_i and M_i = p_{α_i} : u_i ⇛ u_{i−1} ∗₁ A_i, and K_m for Cone(Q_m; c) without the M_i. Then RC(3) holds for Cone(Q_m; c) for every m, in particular for Cone(D² ∗₁ D²; c).
    - *Strict cells.* The strict 2-cells c → y are 1_b, the pure intervals R_ij = A_{i+1} ⋯ A_j and the words W_ij = u_i R_ij. The nonidentity strict 3-cells are the chains W_ij → W_{i−1,j} → ⋯ → W_ℓj, applying M_i, M_{i−1}, …, M_{ℓ+1} in that forced order; each M_i acts on the initial letter u_i, with right whisker R_ij.
    - *RC(3, K_m).* Terms with pure-interval image lie in the pasting context D¹(a) ∗₀ Q_[i,j] (support lemma), so one coherence compares them. Terms with image W_ij factor through one vertical column C_n spanning c → y; item 12's normalisers and formal-term fusion extend to words of any length, the final word comparisons being coherences over C_{j−i+1}.
    - *Sequentialisation.* Generic interchange (X ∗_k Y ⇛ (X ∗_k s₂Y) ∗₂ (t₂X ∗_k Y), a coherence over D³ ∗_k D³) and distribution turn any 3-term into a ∗₂-sequence of K_m-terms and framed generators (L ∗₁ M_i) ∗₁ R, with πL = 1_b and πR = R_ij.
    - *One generator at a time.* A 4-cell over D³ ∗₁ D³ moves a frame comparison δ : R ∗₁ R_t ⇛ r_ij across M_i, giving T_j(E) ∗₂ b_E ⇛ a_E ∗₂ S_i^j with canonical S_i^j = (M_i ∗₁ r_ij) ∗₂ 𝔞. The K_m-factors between consecutive generators are endomorphisms of fixed literal words and are removed by RC(3, K_m).
    - *What it uses.* Every relevant strict 2-word is one initial cone generator followed by a pure interval with pasting support, and the cone 3-generators rewrite that initial generator in a unique order.
14. **A one-generator extension lemma (proved).** Let Λ be a context of dimension ≤ 2 with an acyclic generating 1-graph in which RC(3) holds, and let Γ = (Λ, z : A → B) be such that the only nonidentity 3-cell of the free strict ω-category on Γ is z. Then RC(3) holds in Γ. Proof outline: a 3-head over a 3-dimensional arity P is in the composition case, and is compared by one coherence over P with a boundary-corrected binary composite K_P of P's 3-variables; the additive z-count shows that exactly one substituted 3-argument uses z, so recursion follows one branch. Whiskers of the z-factor are path-supported (∗₁) or point-supported (∗₀) and are removed by explicit 4-coherences over D³, D² ∨₁ D³ ∨₁ D² ∨₁ D² and D²(f) ∨₁ D³(z) ∨₁ D³(e). This gives H ⇛ (L ∗₂ z_rs) ∗₂ R with z-free L, R, which RC(3) in Λ compares with chosen normalisers. It reproves item 12 (Cone(D²; c) has the single 3-generator p_α).
15. **What RC(4) needs.** Varying a 3-variable inside a 4-term is still depth-1 naturality. The additional requirement for RC(4) on Cone(D³; c) is a 5-dimensional compatibility q ∗₃ N_C ⇛ N_B for the chosen 3-term normalisers (q : B ⇛ C); the 4-dimensional fusion used in items 12–13 does not supply it.
16. **Two independent letters with a cut vertex (proved).** In the context a, b, c, d; X : a → b, f⁻ : a → c, f⁺ : b → c, g⁻, g⁺ : c → d; F : f⁻ ⇒ X ∗₀ f⁺, G : g⁻ ⇒ g⁺, the letters F and G act on the two sides of the cut vertex c and commute up to exchange. RC(3) holds there. The normal form of the diagonal 2-cell uses the horizontal composite F ∗₀ G (with horizontal identity factors kept for one-letter transitions); vertical composition of such normal forms is a matrix-style multiplication I ; (m^F ∗₀ m^G) with I : (α ∗₀ β) · (α′ ∗₀ β′) ⇛ (α · α′) ∗₀ (β · β′) over C₂ ∗₀ C₂; a horizontal fold over C₃ ∗₀ C₃ and a horizontal–vertical 4-cell built over C₆ ∗₀ C₆ give fusion; a separate clause absorbs a column that becomes point-supported under substitution.

## Questions

1. **The horizontal case: RC(3) for Cone(D² ∨ D²; c).** For Q = (x, y, z, f, f′ : x → y, g, g′ : y → z, α : f ⇒ f′, β : g ⇒ g′), the cone has three apex edges p_x, p_y, p_z and two 3-generators p_α, p_β. In the hom c → z the letters p_x ∗₀ (α ∗₀ g) and p_x ∗₀ (f ∗₀ β) act on disjoint parts of a path and commute up to exchange, so the strict 2-cells are no longer single forced words.
   - Does the horizontal normal form of item 16 (cut vertex y of Q, whiskered by p_x) give RC(3) for the 2-skeleton?
   - Do p_α and p_β then fit item 13's "prefix ; generator ; suffix" normal form, one generator at a time?
   Prove RC(3), or exhibit two parallel 3-terms with equal strict image and no 4-term between them.
2. **A several-generator extension lemma.** Generalise item 14 to Γ = (Λ, z_1, …, z_k) where every nonidentity strict 3-cell is a composite of whiskered z_i in a uniquely determined order (as in item 13). Is RC(3) in Λ enough, with item 13's sequentialisation?
3. **RC(3) for every join context Cone(Q; c).** By item 4 this gives N^cone through dimension 3. Is there an induction on Q, for example on the number of 2-generators, combining items 13, 14 and 16?
4. **RC(4) for Cone(D³; c).** Construct the 5-dimensional compatibility of item 15, or show it fails.
5. **RC(n) for join contexts.** Possible routes:
   - induction on Q;
   - the support lemma (item 11) combined with a normal form for terms whose strict image uses each top generator once;
   - a comparison between CaTT's term model and Campion's result that the attachment pushouts of loop-free Steiner complexes stay pushouts in flagged weak (∞,n)-categories (arXiv 2311.00200, Thm 5.11, Rem. 5.13).

## What would count as a solution

Any of the following:
- a proof of RC(3) for Cone(D² ∨ D²; c), for the extension lemma of Question 2, or for all join contexts;
- a proof of RC(4) for Cone(D³; c), or of RC(n);
- a counterexample: a join context with two parallel terms of equal strict image and no term between them;
- a reference that constructs cones over coherence terms in CaTT or another algebraic presentation of weak ω-categories.

# Researcher Response

**Question 2 has an affirmative answer. The unique-order hypothesis on the 3-generators can be removed.**

The additional ingredient is a comparison between different 2-dimensional expressions surrounding one 3-generator. Global RC(2), applied with a fresh 2-variable, supplies that comparison; depth-1 naturality moves it across the 3-generator.

This gives the following theorem.

> **3-generator extension theorem.** Let \(\Lambda\) be a CaTT context of dimension at most \(2\), with acyclic generating 1-graph. Let
> \[
> \Gamma=
> \bigl(\Lambda,\ z_1:A_1\to B_1,\ldots,z_k:A_k\to B_k\bigr),
> \]
> where each \(A_i,B_i\) is a pair of parallel 2-terms of \(\Lambda\). Then
> \[
> \boxed{\operatorname{RC}(3,\Gamma)
> \iff
> \operatorname{RC}(3,\Lambda).}
> \]
> There is no restriction on the number, order, whiskering, or composability of the \(z_i\).

For the horizontal cone, this settles the attachment of \(p_\alpha,p_\beta\). Its remaining RC(3) problem lies entirely in its 2-skeleton. At the end, I reduce that 2-skeleton further to a context with four 2-generators.

## 1. Comparing 3-terms modulo 4-terms

Assume \(\operatorname{RC}(3,\Lambda)\). Fix literal parallel 1-terms \(p,q\) of \(\Lambda\).

Define a category \(\mathcal H_\Gamma(p,q)\) as follows:

- objects are 2-terms of the literal type \(p\to q\);
- arrows are 3-terms, identified when a 4-term connects them;
- composition is induced by \(*_2\).

All 2-terms of \(\Gamma\) belong to \(\Lambda\), by the support lemma. Thus this definition includes the boundaries of every relevant 3-term.

The relation on arrows is an equivalence relation. Every 4-term of \(\Gamma\) is invertible, since \(\Gamma\) has no 4-generators. Generic 4-dimensional associators and unitors make the induced composition associative and unital. Similarly, every 3-term of \(\Lambda\) is invertible. These are applications of the empty-own-dimension-support invertibility criterion. [arxiv.org](https://arxiv.org/pdf/2406.12127?utm_source=chatgpt.com)

In the rest of the proof, semicolons denote composition in this quotient category, in diagrammatic order. Equality there means that an actual CaTT 4-term exists; it does not mean judgmental equality of raw terms.

### Chosen representatives of strict 2-cells

For each strict 2-cell \(a\) with boundary
\[
\pi p\to\pi q,
\]
choose a term
\[
\widehat a:p\to q
\qquad\text{with}\qquad
\pi\widehat a=a.
\tag{1}
\]

Such a representative exists with these **literal** boundaries. Lift a binary strict expression for \(a\), inserting path comparisons at its 1-dimensional gluings. Then correct its outside 1-boundaries to \(p,q\). The path comparisons can be chosen to have identity strict images: two 1-terms with the same strict path are terms of that path’s pasting context, so a direct coherence compares them. Acyclicity ensures that the path has distinct vertices.

For each 2-term \(A:p\to q\), choose, using RC(2) in \(\Lambda\),
\[
r_A:A\to\widehat{\pi A}.
\tag{2}
\]
These are invertible 3-terms in \(\Lambda\).

For a 3-term \(U:A\to B\), define its normalised arrow by
\[
[U]^\nu
=
r_A^{-1};U;r_B.
\tag{3}
\]
Its endpoints are the chosen representatives of \(\pi A,\pi B\), and its strict image is \(\pi U\).

The decisive consequence of \(\operatorname{RC}(3,\Lambda)\) is:

> If \(J:A\to B\) is a 3-term of \(\Lambda\), then
> \[
> J;r_B=r_A
> \quad\text{in }\mathcal H_\Gamma(p,q).
> \tag{4}
> \]

Indeed, \(\Lambda\) has no nonidentity strict 3-cells. Consequently \(\pi A=\pi B\), and the two sides of (4) are parallel 3-terms of \(\Lambda\) with equal strict images. RC(3) in \(\Lambda\) compares them.

Thus every normalised base 3-arrow is an identity. Any two choices of base 3-transport with the same endpoints agree in this quotient.

## 2. The comparison lemma for a surrounding 2-expression

This is the step that replaces the restrictions on whiskers in the earlier extension lemmas.

Let \(X\) be a fresh 2-variable with a fixed literal 1-boundary. Consider two 2-terms
\[
F(X),G(X):p\to q
\]
over \((\Lambda,X)\), and assume
\[
\pi F(X)=\pi G(X)
\quad\text{in the free strict 2-category on }(\Lambda,X).
\tag{5}
\]

The equality is required **before substituting a particular term for \(X\)**.

By global RC(2), there is a 3-term
\[
J(X):F(X)\to G(X)
\tag{6}
\]
in \((\Lambda,X)\).

Now let
\[
U:A\to B
\]
be a 3-term of \(\Gamma\), where \(A,B\) have the declared literal 1-boundary of \(X\). Apply naturality to \(J\), varying only \(X\), and substitute
\[
X^-=A,\qquad X^+=B,\qquad X^\uparrow=U.
\]

This is a permitted depth-1 application:

- \(X\) is maximal in \((\Lambda,X)\), so the selected set is upward closed and has context depth \(0\);
- \(J\) has dimension \(3\), while \(X\) has dimension \(2\), so the term depth is \(1\).

Theorem 3.1 of Benjamin–Markakis–Offord–Sarti–Vicary therefore supplies a 4-dimensional naturality comparison. [arxiv.org](https://arxiv.org/pdf/2501.11620?utm_source=chatgpt.com) Writing \(F^\uparrow(U)\) and \(G^\uparrow(U)\) for its two actions, this gives
\[
F^\uparrow(U);J(B)
\ \simeq_4\
J(A);G^\uparrow(U).
\tag{7}
\]

Both \(J(A)\) and \(J(B)\) belong to \(\Lambda\), since their substitutions use only 2-terms. Equation (4) therefore identifies them with the chosen endpoint transports.

It follows that
\[
\boxed{
[F^\uparrow(U)]^\nu=[G^\uparrow(U)]^\nu.
}
\tag{8}
\]

Explicitly, the calculation in \(\mathcal H_\Gamma(p,q)\) is
\[
\begin{aligned}
[F^\uparrow(U)]^\nu
&=
r_{F(A)}^{-1};F^\uparrow(U);r_{F(B)}
\\
&=
r_{F(A)}^{-1};F^\uparrow(U);J(B);r_{G(B)}
\\
&=
r_{F(A)}^{-1};J(A);G^\uparrow(U);r_{G(B)}
\\
&=
r_{G(A)}^{-1};G^\uparrow(U);r_{G(B)}
\\
&=[G^\uparrow(U)]^\nu.
\end{aligned}
\tag{9}
\]

Only RC(2) was used in the enlarged context \((\Lambda,X)\). No instance of RC(3) in that context is assumed.

### Naturality actions versus binary whiskering

For the application below, \(F(X)\) is a binary 2-expression with constants in \(\Lambda\) and exactly one leaf labelled \(X\). Replacing that leaf by \(U\) and evaluating with the standard direct mixed-dimensional compositions gives a binary 3-term, denoted \(F_*(U)\).

We need
\[
F^\uparrow(U)\simeq_4 F_*(U).
\tag{10}
\]
This must be proved without invoking RC(3) in \(\Gamma\).

Proceed by induction on the binary expression \(F\). Naturality commutes with substitution, so the induction reduces to the binary heads. [arxiv.org](https://arxiv.org/pdf/2501.11620?utm_source=chatgpt.com)

- For \(F=X\), the comparison is immediate.
- Constants remain base data.
- For a binary head, its depth-0 naturality action and its direct binary 3-evaluation are parallel full 3-terms over the corresponding genuine pasting context. Depending on the dimensions of the constant argument, this is of the form
  \[
  D^3*_kD^2,\qquad D^2*_kD^3,
  \]
  or \(D^3*_0D^1\) and its reverse. If both arguments vary, it is \(D^3*_kD^3\).

A direct full coherence over that pasting context compares the two 3-terms. Substitute the actual arguments and compose with the inductive comparisons.

Thus (10) follows using direct pasting coherences. In particular, (8) holds for the binary actions:
\[
\boxed{
\pi F(X)=\pi G(X)
\quad\Longrightarrow\quad
[F_*(U)]^\nu=[G_*(U)]^\nu.
}
\tag{11}
\]

### Why this handles changing 1-whiskers

For example, let \(X:p\to q\) be a 2-variable and let \(\beta:g\to g'\) be a horizontally composable 2-term. Put
\[
\begin{aligned}
F(X)&=(X*_0g)*_1(q*_0\beta),\\
G(X)&=(p*_0\beta)*_1(X*_0g').
\end{aligned}
\]
These have the same strict image by interchange.

For \(U:A\to B\), equation (7) gives the comparison between
\[
\bigl((U*_0g)*_1(q*_0\beta)\bigr);J(B)
\]
and
\[
J(A);\bigl((p*_0\beta)*_1(U*_0g')\bigr).
\]

Thus the 1-whisker changes from \(g\) to \(g'\) by naturalising a **3-term in a 2-variable**. No naturality of a 3-term in a 1-variable is required.

## 3. The strict presentation used in the proof

A strict elementary 3-step is a whiskered generator \(C[z_i]\). Here \(C\) is a strict 2-expression with a formal 2-variable \(X\) used once; applying it to \(z_i\) means evaluating that expression on the 3-cell \(z_i\).

The required strict facts are:

1. every strict 3-cell is a vertical composite of elementary 3-steps;
2. equality between such composites is generated by replacement of equal elementary steps and adjacent exchanges;
3. two elementary steps \(C[z_i]\), \(D[z_j]\) are equal precisely when \(i=j\) and \(C=D\) as strict expressions with the formal 2-variable.

These are the atom-and-molecule presentation results in *Polygraphs: From Rewriting to Higher Categories*, Appendix D, especially Propositions D.3.9 and D.3.12. [webusers.imj-prg.fr](https://webusers.imj-prg.fr/~yves.guiraud/articles/polybook.pdf?utm_source=chatgpt.com)

The third fact is what makes (11) applicable. Equality of elementary 3-steps gives equality of the surrounding 2-expressions with \(X\) still formal.

### Weak realisations of strict expressions

Every such strict 2-expression has a weak binary realisation \(F(X)\) with literal outside boundary \(p\to q\).

To construct one, lift its binary operations and insert path 2-comparisons wherever a 1-dimensional gluing agrees strictly but not literally. Finally correct its outside boundary to \(p,q\).

All these corrections are constants with respect to \(X\): the 1-boundary of \(X\) is fixed. Thus the resulting expression still has exactly one leaf labelled \(X\), and it has the required strict image.

Its action on \(z_i\) supplies a weak realisation of \(C[z_i]\).

## 4. Normalised evaluation respects strict equality

We now prove that normalised evaluation of a strict vertical composite does not depend on its presentation.

### 4.1 Replacement of an equal elementary step

Suppose
\[
C[z_i]=D[z_j].
\]
The strict presentation theorem gives \(i=j\) and \(C=D\) as strict 2-expressions with a formal variable.

Choose weak realisations \(F(X),G(X)\), both with outside literal boundary \(p\to q\). Then (5) holds. Applying (11) with \(U=z_i\) gives
\[
[F_*(z_i)]^\nu=[G_*(z_i)]^\nu.
\tag{12}
\]

This also proves independence from the chosen weak realisation: any two choices have the same formal strict image.

### 4.2 Adjacent exchange

For \(k=0,1\), the basic adjacent exchange is
\[
\begin{aligned}
&(U*_k s_2V)*_2(t_2U*_kV)
\\
&\hspace{3em}\simeq_4
(s_2U*_kV)*_2(U*_k t_2V).
\end{aligned}
\tag{13}
\]

There is a direct 4-coherence for (13) over
\[
D^3*_kD^3.
\]
Both displayed 3-terms are full over that pasting context and have the same literal 2-source and 2-target.

For a strict adjacent exchange, choose weak realisations whose lower interfaces match literally. Such choices are available by the same path-boundary correction construction as above. Equation (12) permits replacing the original elementary-step realisations by these choices.

Apply (13), then insert the chosen endpoint transports. Intermediate transports cancel as invertible arrows in \(\mathcal H_\Gamma(p,q)\); any alternative base transport is identified with the chosen one by (4).

This proves invariance under adjacent exchange. Whiskering by the surrounding vertical prefix and suffix preserves the resulting 4-comparison.

Therefore both generators of strict equality preserve normalised evaluation. We have proved:

> A strict 3-cell determines a well-defined normalised arrow between the chosen representatives of its strict 2-boundaries.

The argument allows exchanges. It consequently does not require a unique order of the generator labels.

## 5. Every CaTT 3-term has that evaluation

Let \(U:A\to B\) be an arbitrary 3-term of \(\Gamma\), with common literal 1-boundary \(p\to q\).

Use the boundary-corrected sequentialisation established in items 13–14:

- a 3-head over an arity of dimension at most 2 gives a term of \(\Lambda\);
- a 3-head over a 3-dimensional arity is compared by a 4-term with its binary evaluation, after correcting its literal 1- and 2-boundaries;
- the inserted corrections use only arguments of dimension at most 2, hence belong to \(\Lambda\);
- generic interchange and distribution turn the binary evaluation into a vertical sequence of base 3-terms and individually whiskered \(z_i\)'s.

The recursion is on original proper 3-dimensional substitution arguments. Newly introduced binary operation heads are not expanded again.

Every individually whiskered generator is the binary action of a 2-expression with one formal variable. Equation (10) justifies its interpretation in §4.

Normalisation removes every intervening base 3-term by (4). Hence
\[
[U]^\nu
\]
is exactly the well-defined normalised evaluation of its strict 3-cell \(\pi U\).

For parallel \(U,V:A\to B\) with \(\pi U=\pi V\), it follows that
\[
[U]^\nu=[V]^\nu.
\]
Their normalisations use the same \(r_A,r_B\). Cancelling these invertible arrows gives
\[
[U]=[V]
\quad\text{in }\mathcal H_\Gamma(p,q).
\]
By the definition of that category, a CaTT 4-term \(U\to V\) exists.

This proves
\[
\operatorname{RC}(3,\Lambda)
\Longrightarrow
\operatorname{RC}(3,\Gamma).
\tag{14}
\]

Only finitely many choices and comparisons are needed for any given pair of terms and a finite derivation of their strict equality.

## 6. The converse

Suppose \(\operatorname{RC}(3,\Gamma)\), and take parallel 3-terms \(U,V\) of \(\Lambda\) with equal strict images.

Weaken them to \(\Gamma\) and obtain a 4-term
\[
H:U\to V.
\]
Since \(\Gamma\) has no 4-generators, \(\pi H\) is the identity 4-cell on the common strict image of \(U,V\). That strict image uses only variables of \(\Lambda\).

The support lemma therefore excludes every \(z_i\) from \(H\). Strengthening returns \(H\) to \(\Lambda\). Thus
\[
\operatorname{RC}(3,\Gamma)
\Longrightarrow
\operatorname{RC}(3,\Lambda),
\]
completing the theorem.

## 7. Consequence for every join context

Write
\[
\Delta=\operatorname{Cone}(Q;c),
\qquad
\Delta_{\le2}
\]
for its dependency-closed subcontext of variables of dimension at most 2.

The extension theorem gives the reduction
\[
\boxed{
\operatorname{RC}(3,\Delta)
\iff
\operatorname{RC}(3,\Delta_{\le2}).
}
\tag{15}
\]

For the forward implication, take a comparison problem in \(\Delta_{\le2}\) and fill it in \(\Delta\). By item 2, the strict image of that filler is an identity. The support lemma then strengthens it back to \(\Delta_{\le2}\).

For the reverse implication, first adjoin all 3-generators of \(\Delta\), using the theorem. Every 3-term of \(\Delta\) already belongs to this subcontext, by the support lemma. The resulting 4-filler can be weakened into the full cone.

The generating 1-graph here is acyclic, as required: a directed 1-cycle would give a nonidentity strict endo-1-cell, contrary to item 2.

Thus **the obstruction to RC(3) for joins is entirely a problem about their 2-skeletons**. Neither interactions among cone 3-generators nor higher cone generators add an independent RC(3) obligation.

## 8. The horizontal cone reduces to four 2-generators

For Question 1, use the notation
\[
\begin{gathered}
a=p_x,\qquad b=p_y,\qquad e=p_z,\\
u=p_f,\qquad v=p_{f'},\qquad
s=p_g,\qquad t=p_{g'},\\
M=p_\alpha,\qquad N=p_\beta.
\end{gathered}
\]
Thus
\[
\begin{aligned}
u&:b\to a*_0f,&
v&:b\to a*_0f',\\
s&:e\to b*_0g,&
t&:e\to b*_0g'.
\end{aligned}
\]

Let \(K\) be the horizontal cone with \(M,N\) deleted. The theorem gives
\[
\operatorname{RC}(3,\operatorname{Cone}(D^2\vee D^2;c))
\iff
\operatorname{RC}(3,K).
\tag{16}
\]

There is a further support reduction. Let
\[
S=K\setminus\{v,t\}.
\]
Its 2-generators are exactly
\[
\alpha:f\to f',\qquad
\beta:g\to g',\qquad
u:b\to a*_0f,\qquad
s:e\to b*_0g.
\]

Then
\[
\boxed{\operatorname{RC}(3,K)\iff\operatorname{RC}(3,S).}
\tag{17}
\]

Here is the strict classification needed for (17).

The strict 2-cells between paths \(c\to y\) form the category
\[
L:\qquad
b\xrightarrow{u}af\xrightarrow{a\alpha}af',
\qquad
b\xrightarrow{v}af',
\]
with \(v\) distinct from \(u\cdot a\alpha\). Let \(R\) be the category generated by \(g\xrightarrow{\beta}g'\).

Between the paths \(c\to z\) other than \(e\), the strict 2-cells form \(L\times R\). The path \(e\) adds the two initial steps \(s,t\). Every nonidentity strict 2-cell starting at \(e\) therefore has one of the forms
\[
s\cdot(\ell*_0r),
\qquad
\ell\in\{1_b,u,v,u\cdot a\alpha\},
\quad r\in\{1_g,\beta\},
\tag{18}
\]
or
\[
t\cdot(\ell*_0 1_{g'}),
\qquad
\ell\in\{1_b,u,v,u\cdot a\alpha\}.
\tag{19}
\]

To verify this, the first nonidentity step on \(e\) must be \(s\) or \(t\). Subsequent steps act on the two sides of \(y\); interchange moves the right-hand \(\beta\) past the left-hand steps. The left-hand sequence is one of those listed.

Consequently:

- a strict 2-cell never uses both \(u\) and \(v\);
- if it uses \(v\), its support uses neither \(\alpha\) nor \(f\), so that support can be renamed by \(v\mapsto u,\ f'\mapsto f\);
- a strict 2-cell never uses both \(s\) and \(t\);
- if it uses \(t\), its support uses neither \(\beta\) nor \(g\), so that support can be renamed by \(t\mapsto s,\ g'\mapsto g\).

These are bijective renamings of the relevant supports, not identifications of distinct variables. The other homs use the corresponding subcontexts. Hence every strict 2-cell support in \(K\) is isomorphic to a dependency-closed subcontext of \(S\).

Since \(K\) has dimension 2, every strict 3-cell is an identity on a strict 2-cell. The support lemma therefore proves (17): strengthen a comparison problem to its support, rename into \(S\), fill there, and strengthen the filler back to that support. The converse follows by strengthening along \(S\subseteq K\).

Combining (16) and (17),
\[
\boxed{
\operatorname{RC}(3,\operatorname{Cone}(D^2\vee D^2;c))
\iff
\operatorname{RC}(3,S).
}
\tag{20}
\]

A strict 2-cell with full support \(S\) is
\[
w=
s*_1
\bigl((u*_1(a*_0\alpha))*_0\beta\bigr).
\tag{21}
\]

The remaining normalisation problem is therefore the combination of:

- the left vertical word \(u*_1(a*_0\alpha)\);
- its horizontal interaction with \(\beta\);
- the initial step \(s\).

Item 16 supplies the one-left-event cut-vertex case. Substituting the two-event word for that event supplies particular comparison terms, but does not establish substitution fusion for arbitrary \(S\)-terms. That fusion statement remains necessary to prove RC(3) for \(S\).

**The completed result is the extension theorem of Question 2, without the ordering restriction, together with reductions (15) and (20).** The horizontal 2-skeleton normalisation, RC(4), and the all-dimensional conjecture are not proved here.
