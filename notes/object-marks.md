# Object marks on object terms (ledger S36)

Owner: MKL. Agda: `src/CaTTExp/Uniform/ObjectMarks.agda`. Spec: §3.2, §9.1.

## 0. Summary

- **The problem.**
  - Object marks (`grpd_k`, `iord`, `ord`, `lsplit`, `rsplit`) could only be sent by a substitution to an object *variable* with the same mark, and constants carried none.
  - So a lemma proved over `(C : ⋆)^ord` could not be applied to ℕ, ℤ, a limit, ⟦Γ⟧ or ‖A‖_n.
  - Nothing related these marks to chapter 9's `trunc n`, which already had a judgment on object terms.
  - The same gap blocked INIT. A model of Δ with `X : ⋆^grpd` in a constructed target must certify `grpd` for that target, and there was no way to do so.
- **The decision.** The h-levels and the object marks are merged into **one family of atomic object marks**. There is one judgment `Γ ⊢ C m` on object terms, one entailment relation between atoms, and one rule per object former. A marked object variable may be sent to **any object term** whose mark is derivable. §4 compares this with two narrower options.
- **The entailments** (§2):
  - `trunc n ⇒ trunc n′` for n ≤ n′;
  - `trunc n ⇒ grpd_k` for k ≥ n + 1;
  - **`trunc n ⇒ ord`, `iord`, `lsplit`, `rsplit` for n ≤ 1**;
  - `grpd_k ⇒ grpd_k′` for k ≤ k′;
  - **`grpd_k ⇒ iord` for k ≤ 2**;
  - `ord ⇒ iord`, `lsplit`, `rsplit`.
- **Results.**
  - [proved, Agda] The judgment is decidable, closed under entailment, and stable under substitution into marked variables (`md-up`, `md-subst`).
  - [proved, Agda, relative to the per-former facts] It is sound in strict models.
  - [proved on paper] The per-former facts, except as noted next.
  - [conditional] The limit clause for the inner marks (`iord`, `ord`, the splits) needs a hypothesis (PW) on V + S (§3.4).
  - [open] INIT with an inner mark on X needs closure of the marked class (§3.6).
- **Consequences.** ℕ, ℤ, Bool, every set, every 1-category object (⟦Γ⟧ of a graph, ‖A‖₁), limits of these, and Hom of a 2-truncated object are all `ord`. So every lemma over `(C : ⋆)^ord` applies to them. A groupoid is `iord`, though not derivably `ord`.

## 1. The rule

**Atoms.** An atomic object mark is one of:
- `trunc n` (n ≥ −2; the declaration form is `⋆^{≤n}`);
- `grpd_k` (k ≥ 1);
- `iord`, `ord`, `lsplit`, `rsplit`.

A declaration `(C : ⋆)^{m₁, …, m_r}` carries finitely many atoms.

**Judgment.** `Γ ⊢ D m` for an object term D and an atom m. It is generated by:

```
(mark)    (C : ⋆)^{…, a, …} ∈ Γ,  a ⊒ m                  ⟹  Γ ⊢ C m
(ent)     Γ ⊢ D a,  a ⊒ m                                ⟹  Γ ⊢ D m     (admissible: md-up)
(O-unit)  ⊤ trunc −2;  ⊥ trunc −1
(O-graph) Γ′ a finite graph context (possibly localised) ⟹  ⟦Γ′⟧ trunc 1
(O-trunc) ‖A‖_n trunc n
(O-hom)   C trunc (n+1) ⟹ Hom_C(a, b) trunc n;   C grpd_{k+1} ⟹ Hom_C(a, b) grpd_k
(O-lim)   every object vertex of γ has m  ⟹  lim_{Γ^μ}[γ] m       (every atom m; any marking)
(O-coprod) A, B trunc n,  n ≥ 0  ⟹  A ⊔ B trunc n
(O-init)  X carries a in Δ  ⟹  μΔ a                       (read off Δ)
(T-init)  as in §9.1  ⟹  μΔ trunc n
```

These are chapter 9's T-unit, T-graph/T-loc, T-trunc, T-hom, T-lim (now for every atom), T-coprod and T-init. To them are added (O-init), the inner-mark half of (O-lim), and the entailment table of §2. T-cum is the entailment `trunc n ⇒ trunc n+1`.

**Substitution.** A substitution Δ ⊢ γ : Γ must certify every declared atom: Δ ⊢ γ(C) a for each `(C : ⋆)^{…, a, …}`. The old restriction ("an object variable with the same mark", "constants carry no marks") is dropped.

**Rules that read object marks.** These are (OBJ-k), (ORD), (OP-inv_S′)(iii) through ord-tgt, (COH-ord), and the split marks in S(Γ) of §2.3. They now read the judgment on γ(aᵢ), instead of asking for a marked variable. Their soundness proofs use only the semantic content of the mark at the denoted object (§3), so they are unchanged.

**Decision procedure.** The judgment is syntax-directed on the object term.
- Each former contributes one clause.
- (mark) and (ent) are a finite search over the declared atoms with the decidable relation ⊒.
- (O-hom) translates the query by one level.
- T-init and T-coprod query the parameters at the weakest level n ≥ 0 whose `trunc n` entails m.

`md` in the Agda module is exactly this procedure.

## 2. The entailments

Read each mark in a model as a condition on the homs 𝒦(X, C), for every X:
- `trunc n`: every cell of level > n is an identity;
- `grpd_k`: every cell of hom-dimension ≥ k is invertible;
- `iord`: every inner letter is invertible;
- `ord`: every inner letter is trivial;
- `lsplit`, `rsplit`: the split laws hold.

**Lemma 2.1 (inner letters have hom-dimension ≥ 2).** Every inner letter whose hom lands in 𝒦(X, C) has hom-dimension at least 2.

*Argument.*
- An interchanger of a p-cell and a q-cell across a k-cell has dimension p + q − k (Gray dimension count). For an inner one, k ≥ 1 and p, q ≥ k + 1. So its dimension is at least k + 2 ≥ 3, and its hom-dimension is at least 2.
- The kernel of π₁ is generated by these interchangers (requirement 4). Every inner letter is built over an inner crossing, and its dimension is at least that of the crossing ((F1), (F3) of `uniform-marks.md`).
- The second step is cited, not re-proved. The weaker bound, hom-dimension ≥ 1, is immediate: F_{V+S} has no inner letters among its 1-cells. **[proved for interchangers; cited for the other inner letters.]**

**Entailment table.** Each row follows from Lemma 2.1 and the readings above:
- `trunc n ⇒ trunc n′` (n ≤ n′): trivial.
- `trunc n ⇒ grpd_k` (k ≥ n + 1): identities are invertible.
- `trunc n ⇒ ord` (n ≤ 1): every cell of hom-dimension ≥ 2 is an identity, so every inner letter is one (Lemma 2.1).
  - For n ≤ 0, only the weak bound is needed. This covers every case the ledger asked for (`trunc 0 ⇒ ord`).
- `ord ⇒ iord`, `lsplit`, `rsplit`: chapter 2, §2.3.
- `grpd_k ⇒ grpd_k′` (k ≤ k′): trivial.
- `grpd_k ⇒ iord` (k ≤ 2): by Lemma 2.1.
  - **New consequence.** Every groupoid, and every (∞, 1)-category object, is `iord`. So (ORD) and (OP-inv_S′)(b) apply to them without a separate mark.

The table is closed under composition (Agda `ent-trans`). It is not complete: `grpd_1 ⇒ ord` is not claimed, and no strict model is given for it. A strict ω-groupoid has identity inner letters, but an algebra of V + S whose homs into C are groupoids with directed inner interchange need not.

## 3. Soundness

**Models.** Strict models, as for the uniform rules of spec §3.6. (§3.2–3.3 read `grpd_k` in oriented (∞, ω)-categories; there the rows `trunc n ⇒ grpd_k` and `grpd_k ⇒ iord` hold as well, by the same dimension count, and `ord` has no written weak reading, §6(d).) The models are algebras of an admissible theory E ⊇ V + S, with strict inverses. `trunc n` is read **strictly**: every cell of level > n into C is an identity. This reading makes T-fill, T-inv and T-ctr sound by identities: fill(u, v) := 1, since parallel identity cells are equal. Chapter 9 proves its rules in Cat_ω. The strict counterparts used below are proved here, except where marked.

**3.1 (mark), (ent).** By the certification of substitutions and §2.

**3.2 (O-unit), (O-trunc), (O-init).** ⊤ and ⊥ are immediate. For ‖A‖_n and (O-init): the generic model η : Δ[μΔ/X] is a substitution, so it must certify X's marks (§3.2). So "μΔ has X's marks" is part of INIT-form's conclusion, and its soundness is the soundness of INIT for the marked class (§3.6).

**3.3 (O-hom).** A cell of level h into Hom_C(a, b) is a cell of level h + 1 into C. Hom_C(a, b) is a pullback of the lax cotensor [⟦D¹⟧, C], and maps into a cotensor are maps out of a Gray product. So identities and inverses transfer, as in T-hom. The query table `homQ` follows from this. For example, Hom_C(a, b) is `ord` when C is `trunc 2`, because the hom is then `trunc 1`. No clause transfers `ord` itself from C to its homs (§6).

**3.4 (O-lim).**
- **`trunc`, `grpd`.** In a strict model, a limit is a limit of hom ω-categories: post-composition with the legs gives 𝒦(X, lim D) ≅ lim_i 𝒦(X, Dᵢ). Each post-composition is a strict ω-functor ((F2): whiskering by lower cells), so it preserves identities and inverses. A cell all of whose legs are identities (invertible) is an identity (invertible), with the tuple of inverses as inverse. **[proved]**
- **Inner marks.** The projection of an inner letter into lim D is the whiskered letter p_i ▷ ℓ(A, B). To read the mark of Dᵢ on it, we need:

  > **(PW)** Post-whiskering by a 1-cell p sends a bare inner letter to the bare inner letter of the whiskered operands: p ▷ ℓ(A, B) = ℓ(p ▷ A, p ▷ B).

  - Given (PW), each projection of an inner letter into lim D is an inner letter into Dᵢ, and the legs are jointly faithful. So `iord`, `ord` and the splits pass to the limit.
  - (PW) holds in strict Gray-enriched categories and in strict ω-categories, where both sides are identities.
  - Both sides are parallel and have the same Gray image. In V + S such pairs are not always equal: E13 gives the loop H against 1_w. So (PW) is a real hypothesis. It is expected from requirement 5, taking the substitution A′ ↦ p ▷ A on the context of ℓ, but that does not by itself identify the two cells.
  - **[conditional on (PW); ledger S36(a)]**
  - Without (PW), a limit of `trunc 1` objects is still `ord` through `trunc`, which is unconditional.

**3.5 (O-coprod), (O-graph).**
- *(O-coprod).* In an extensive strict model, a cell into A ⊔ B splits along the decomposition of its domain. **[proved given extensivity, the strict counterpart of DESC's disjoint universal coproducts]**
- *(O-graph).* The free strict ω-category on a graph is a 1-category, and so is its localisation.
  - Fun^lax(X, C) is a strict n-category when C is: a k-transfor with k > n has all its components of dimension > n, so they are identities, and its two boundaries coincide.
  - So every cell of level > 1 into ⟦Γ′⟧ is an identity. **[proved, sketch]**

**3.6 T-init and (O-init) for an inner mark.**
- *T-init in strict models.* It needs initial algebras of the strict model to be computed inside the marked class, as in Cat_ω (§9.1, Semantics). This is taken as the strict counterpart of chapter 9's argument: the Adámek tower stays inside strict n-categories. **[sketch]**
- *INIT with `X : ⋆^{iord}` or `⋆^{ord}`.* This needs the class of `ord` objects to be closed under the colimits of the construction. That is open in strict models. In the intended (∞, ω) model every object is expected to be `ord` (`ord-recovers-two-tier.md` §2), so there the class is everything. **[open; ledger S36(b)]**
- *ℕ, ℤ, Bool, W-types.* Their `ord` mark goes through T-init or T-coprod and `trunc 0 ⇒ ord`, so it does not depend on (b).

**3.7 Substitution.** If γ certifies every declared atom, every derived judgment survives: Γ ⊢ D m implies Δ ⊢ D[γ] m. The proof is by induction on D. The variable case is certification plus closure under entailment (`md-up`). Every other former commutes with substitution, and its premises are judgments on subterms. **[proved, Agda `md-subst`]**

**3.8 What the Agda checks.**
- **Checked:**
  - `ent-refl` and `ent-trans`;
  - `md` decidable by construction;
  - `md-up`;
  - `md-subst`;
  - `ent-sound`: the table of §2 in every `Base`, from the reading of the marks, the fact "identities are invertible", Lemma 2.1 as two fields, and `ord ⇒ iord, lsplit, rsplit`;
  - `sound`: every derivable judgment holds in every model given the per-former facts of `Formers`.
- **Not checked:** the per-former facts themselves (§§3.2–3.6) and Lemma 2.1. These are paper inputs, listed as fields, and the inner-mark limit fields are marked (PW).
- **Examples by evaluation:**
  - `ord`: ℕ, ⊤ ⊔ ⊤, ‖A‖₀, ‖A‖₁, ⟦Γ′⟧, a limit of ℕ and Hom of a `trunc 2` object;
  - not `ord`: ‖A‖₂, S¹ (only `grpd_1` and `iord`), a groupoid variable (`iord`, not `ord`), a limit involving a groupoid;
  - not `trunc 0`: μ(X, A → X) over an unmarked A.
- **Substitution example:** a lemma over `(C : ⋆)^ord` applied at ℕ, `lemma-at-ℕ`.

## 4. Options compared (project rules 3 and 4)

| | (A) bridge rules only | (B) one mark family (chosen) | (C) user-defined object classes |
|---|---|---|---|
| What it adds | `trunc 0 ⇒ ord` and similar implications between two judgments; the substitution rule still asks for a marked variable | atoms with one entailment relation and one judgment on object terms; substitution by any term with the derived mark | a mark for each class of objects the user declares (a predicate on objects) |
| Lemma over `C : ⋆ ord` at ℕ | no: ℕ is not a variable | yes (`lemma-at-ℕ`) | yes |
| INIT with `X : ⋆^grpd` into a constructed groupoid target | no | yes, when the target's `grpd` is derivable | yes |
| `grpd_2 ⇒ iord`, `trunc 1 ⇒ ord` | each needs its own rule | rows of one table, closed under composition (`ent-trans`) | the user's burden |
| Decidable | yes | yes (`md`) | no in general: the class is a predicate, and membership of μΔ is already undecidable for `trunc` with cell variables (§9.1) |
| Allowed rule classes (§0.2) | yes | yes: marks stay judgments, no universe | no: a predicate on objects quantified by the user is a universe of classes |

(B) is the most general option that stays in the allowed rule classes, and it contains (A).

(C) is not needed for the main use of user-defined classes. INIT already builds the reflection into a marked class: μ(X : ⋆^{m}, g : A → X) is the m-reflection of A whenever the class is reflective (‖A‖_n for `trunc n`, the groupoid reflection for `grpd`). So (B) gets reflections for free, for every atom whose class is closed as in §3.6.

**Relation to mark schemes (S35, spec §3.9).** Schemes are cell marks. The object atoms of (B) are ∀-closures of built-in schemes: `grpd_k` is "every cell into C of hom-dimension ≥ k is Inv". The natural extension within (B) adds an atom ∀P_{≥k} for a user scheme P, with these entailments:
- ∀P_{≥k} ⇒ ∀P_{≥k′} for k ≤ k′;
- `trunc n` ⇒ ∀P_{≥n+1} whenever P holds of identities.

It keeps decidability of the judgment, because the scheme's own closure is certified once (S35(f)). It is not added here, because no current lemma needs it.

**How initiality interacts with marks** (the question from the walkthrough):
- INIT reads the marks of X off Δ. The initial model lives in the marked class, and μΔ has X's marks by (O-init).
- A model of Δ in a target A must certify those marks on A. Under (B) this is the judgment on A, so a constructed target with a derivable mark is allowed.
- T-init adds `trunc n` (and so `ord` for n ≤ 1, `grpd_{n+1}`) when Δ has the shape of §9.1, even with X unmarked. So ℕ and ℤ are sets, hence `ord`, and every lemma over `C : ⋆ ord` or `C : ⋆ grpd_1` applies to them.
- Recursion (INIT-J1) into a marked object is an ordinary substitution and needs nothing more.

## 5. Spec changes

- **§3.2.**
  - The judgment `Γ ⊢ C m` is on object terms, for the merged atoms.
  - The substitution clause allows any object term.
  - The entailment table and the former rules are listed, with a pointer to §9.1 for the h-level formers.
- **§3.6.** ord-tgt and (COH-ord) read the judgment on γ(aᵢ).
- **§9.1.**
  - `trunc n` is one atom of the chapter 3 family.
  - T-lim holds for every atom (inner atoms conditional on (PW)), and (O-init) is added.
  - The relation to `grpd_k` gains `trunc n ⇒ ord` (n ≤ 1) and `grpd_k ⇒ iord` (k ≤ 2).
