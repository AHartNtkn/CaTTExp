# Cones over coherence terms in CaTT (N^cone), round 4

*A self-contained problem. No knowledge of the project that posed it is assumed. Rounds 1–3 and their verified answers are in `answered/cone-over-coherences-2026-11-18.md`, `answered/cone-over-coherences-r2-2026-11-18.md` and `answered/cone-over-coherences-r3-2026-11-18.md`; nothing answered there is re-asked. Questions are at the end, smallest first.*

## Background

**CaTT.** Contexts list variables `x : A`, where a type is `⋆` or `a →_A b` with a, b terms of type A. Terms are variables or `coh_{Q,B}[γ]`, where Q is a *pasting context* (a context presenting a globular pasting diagram), B is a type over Q satisfying the usual side conditions (either both boundary terms are full in Q, the *coherence case*, or each is full in the matching boundary of Q, the *composition case*), and `γ : Δ ⊢ Q` is a substitution. Reference: Finster–Mimram, *A type-theoretical definition of weak ω-categories* (LICS 2017); Benjamin–Finster–Mimram, *Globular weak ω-categories as models of a type theory* (2021). Composition order below is diagrammatic, and `u ∗_k w` denotes the binary composite along a k-cell, which is itself a composition coherence over two disks glued along a k-disk. For a term t of dimension m ≥ 1 write `σt, τt` for its source and target, and `σʲt` for the iterated source.

**Cone over a globular context.** Call a context *globular* if every variable's type is `⋆` or `a → b` with a, b variables; every pasting context is globular. For globular Γ, the *specified cone* `Cone(Γ; c)` extends Γ by an object `c : ⋆` and one variable `p_t` for each variable t of Γ, in order:

```
p_x : c → x                                                   (dim x = 0)
p_t : p_{τt}  →  p_{σt} ∗_{m−1} (p_{σ²t} ∗_{m−2} ( … (p_{σᵐt} ∗₀ t)))      (dim t = m ≥ 1)
```

So `f : x → y` gets `p_f : p_y ⇒ p_x ∗₀ f`, and `α : f ⇒ g` gets `p_α : p_g ⇛ p_f ∗₁ (p_x ∗₀ α)`. This is a well-formed context for every globular Γ (by induction on the variables: each composite in the target is well formed because the projections of the boundary variables already have the matching types). It is the cone of T. J. Mikhail's Thm 3.3 (*A type-theoretic definition of lax (∞,∞)-limits*, arXiv 2412.13310), lax at the vertices. When Γ is a pasting context, the strict ω-category freely generated by `Cone(Γ; c)` is the Ara–Maltsiniotis join `c ⋆ Γ`, with `p_t ↦ c ⋆ t`.

**Cones over arbitrary contexts.** In a general context a variable may have composite boundaries, e.g. `τ : f ∗₀ g ⇒ h`. The cone variable over τ then needs a cone cell `P(f ∗₀ g)` over the *term* `f ∗₀ g`. Extend p from variables to all terms:

```
P(x)              := p_x
P(coh_{Q,B}[γ])   := Π(Q, B)[Cone(γ)]
```

where `Cone(γ) : Cone(Γ; c) ⊢ Cone(Q; c)` sends `q ↦ γ(q)`, `c ↦ c`, `p_q ↦ P(γ(q))`, and `Π(Q, B)` is a chosen term of `Cone(Q; c)`. For a term t of dimension m ≥ 1 put

```
T(t) := P(σt) ∗_{m−1} (P(σ²t) ∗_{m−2} ( … (P(σᵐt) ∗₀ t))).
```

For `c₀ := coh_{Q,B}[id_Q]`, of dimension n, the term `Π(Q, B)` must have type

```
Π(Q, B) : P(τc₀) → T(c₀)          (an (n+1)-term of Cone(Q; c)).
```

This type is well formed once P is defined on the boundary terms of c₀, which have dimension < n. So the definition is a recursion on dimension. Within a dimension, the boundary terms of an n-coherence may themselves contain n-dimensional subterms only in the composition case, through lower-dimensional factors, so the recursion is well founded with the order "lower dimension first, then structural" .

## Statement

> **Conjecture N^cone.** For every pasting context Q and every type B such that `coh_{Q,B}` is a valid coherence, there is a term `Π(Q, B)` of `Cone(Q; c)` of type `P(τc₀) → T(c₀)`, where P on the boundary of c₀ is defined from Π at lower dimensions as above. Moreover Π can be chosen so that, in the free strict ω-category on `Cone(Q; c)`, `π(Π(Q, B)) = c ⋆ π(c₀)` (the join of c with the strict image of c₀).

The strict-image clause is part of the statement because the inductive step uses it: it guarantees that `P(u)` has strict image `c ⋆ π(u)` for every term u.

Consequence: for every CaTT context Γ, the extension `Cone(Γ; c)` (with P in place of p in the types of the cone variables) is a well-formed context. This is a precise form of Mikhail's Conjecture 3.6 ("cones exist over arbitrary contexts"), restricted to a specified construction.

## What is known

1. **Dimension 1 (proved).** For the composite of a chain `x₀ —f₁→ … —f_m→ x_m`, Π is the vertical composite of the whiskered cone generators `p_{f_m}`, `p_{f_{m−1}} ∗₀ f_m`, … followed by the associator coherence κ over `c → x₀ → … → x_m`.

2. **Every relative-coherence witness in a join context strictifies to an identity.** The free strict ω-category on `Cone(Q; c)` is the join `c ⋆ Q`, which is ν(K) for a strong Steiner complex K (Ara–Maltsiniotis, *Joint et tranches*). In a strong Steiner complex every positive cycle is zero, so every endo-cell of c ⋆ Q is an identity.

3. **Reduction to relative coherence.** Write **RC(r) for Δ** for the statement: any two parallel r-terms of Δ with equal strict images are connected by an (r+1)-term.
   - If RC(1), …, RC(n) hold for `Cone(Q; c)` for every pasting context Q, then N^cone holds through dimension n, in both the coherence and the composition case. (Lift strict cells to terms, then correct faces one dimension at a time with RC witnesses; the strict image is unchanged.)

4. **Fixed dimension suffices (round 2).** For the standard recursively defined binary compositions, a syntactic *cut translation* D lowers the dimension of terms crossing a chosen 0/1 colouring of the 0-variables, with D(Σt) ≡ t, D(e ∗₀ u) ≡ D(u), D(u ∗_k v) ≡ D(u) ∗_{k−1} D(v), and D(t[θ]) ≡ D(t)[D(θ)]. With the substitution `e_Q : Cone(ΣQ; d) ⊢ Cone(Q; c)` (U ↦ d, V ↦ S, Σc ↦ p_S, Σq ↦ p_N ∗₀ q̄, Σp_q ↦ p_{q̄}) it gives a literal retraction D(L_Q t) ≡ t, hence

   ```
   RC(r+1, Cone(ΣQ; d))  ⇒  RC(r, Cone(Q; c)),
   [∀Q RC(n, Cone(Q; c))]  ⇒  [∀Q ∀ r < n RC(r, Cone(Q; c))]  ⇒  N^cone through dimension n.
   ```

5. **Dimension 2 holds.** RC(1) and RC(2) hold in every CaTT context, so N^cone holds in dimension 2. There is also an explicit term for `α ∗₀ β`.

6. **The first 3-dimensional instance (round 2).** With generic schemes for P(1_f) and P(α ∗₁ β) over D¹ and D² ∗₁ D², the unitor `c₀ : α ⇛ α ∗₁ 1_g` over D² has an explicit 4-term `P(α ∗₁ 1_g) → P(α) ∗₂ (p_f ∗₁ (p_x ∗₀ c₀))`, a chain of ten 4-cells built from six auxiliary coherences over pasting contexts, with strict image `1_{p_α} = c ⋆ π(c₀)`. It works for every coherence c₀ of that type.

7. **Where the lax-square argument stops.** RC(3) holds on the lax square (x⁻, x⁺, y⁻, y⁺; x↑, y↑, f⁻, f⁺; F : f⁻ ∗₀ y↑ ⇒ x↑ ∗₀ f⁺): for a 2-term with strict image F, exactly one 0-column of its arity carries F, the others are point-supported and factor literally through point contexts, and this factorisation is stable under substitution. It gives normalisers compatible with every 3-term. In `c ⋆ Q` the apex c is the unique 0-source and the last vertex x_k of Q is the unique 0-sink, but a term like `p_x ∗₀ α` has a discarded column carrying the nonidentity edge `p_x : c → x`, so the point-support step fails.

8. **A tool that handles one fixed edge (naturality round 3).** On the cylinder of a composable pair (x → y → z), a column that carries a lax square but does not span the unique source and sink factors literally through a retained pasting context `C_n ∗₀ D¹(h)` or `D¹(h) ∗₀ C_n` (C_n a vertical n-chain, D¹(h) one edge), where every relevant substitution sends h to the **same edge variable**. With fixed-whiskering 3-cells, path comparisons after whiskering, a compatibility cell φ^h with the vertical fold, and evaluation fusion, this gives normalisers and RC(3) for that cylinder. The proof is in `answered/naturality-arbitrary-depth-r3-2026-11-18.md`.

9. **Strict case.** In strict ω-categories `c ⋆ −` is functorial on cells, so the strict analogue of N^cone holds in every dimension.

10. **Loop-freeness is needed.** In (x, a : 1_x → 1_x) the weak free object groupoidifies to S² and the strict one to K(ℤ, 2), so RC(3) fails there.

11. **The support lemma (round 3, proved).** For every CaTT context Γ and term t, the generators used by the strict image of t form exactly the dependency-closed set of variables of t:
    ```
    supp_{πΓ}(πt) = supp_Γ(t).
    ```
    Strict support is invariant under the strict axioms. The proof is by induction on derivations: a composition head goes to the total composite, and a coherence head goes to 1_{πs} with s full.

    *Consequence.* A term whose strict image is supported in a dependency-closed sub-context S is literally a term of S. So parallel terms with strict image 1_w are joined by one full coherence over supp(w). Also, a point-supported column of an arity factors literally through a point, by renaming that point.
12. **RC(3) for Cone(D²; c) (round 3, proved on paper).** Write a = p_x, b = p_y, u = p_f : b ⇒ a∗₀f, v = p_g : b ⇒ a∗₀g, w = a∗₀α, d = u∗₁w, M = p_α : v ⇛ d, and K = Cone(D²; c) without M.
    - *Strict cells.* The nonidentity strict 2-cells are α, u, v, w and d. The only nonidentity strict 3-cell is M, which has no whiskers and does not compose with itself.
    - *RC(3, K).* Each 2-term with strict image u, v or d has exactly one active column, a vertical chain C_n, while its other columns are point-supported. Normalisers N_A : A ⇛ ê_{p,q} keep the literal 1-boundaries. They come from a generic comparison χ_r over C_n followed by an evaluation E(σ; B) that is the same for every full r : B.
    - *Fusion.* A fusion lemma, proved by induction on the formal term with only depth-1 naturality, gives N_T ∗₂ N_B ≃ N_A for every 3-term T.
    - *Adjoining M.* Every U with πU = M satisfies 𝒯(U) ≃ A_U ∗₂ M ∗₂ B_U, with A_U and B_U in K. Level-1 whiskers are removed by depth-1 naturality and level-0 whiskers by one coherence over the 3-disc. RC(3, K) then compares the prefixes and suffixes.
    - *What it uses.*
      - Every 2-cell involving u or v spans c → y.
      - The other non-point whisker a∗₀α has a pasting context as its support.
      - The nonidentity vertical word is one of u, v, w, or u followed by w.
      - M has no whiskers.

## Questions

1. **Two 3-generators: RC(3) for Cone(D² ∗₁ D²; c) and Cone(D² ∨ D²; c).**
   - *Vertical case.* For Q = (x, y, f, g, h, α : f ⇒ g, β : g ⇒ h), the cone has the 3-generators p_α and p_β. Their whiskered images can compose along a 2-cell, so "exactly one M" (item 12) fails.
   - *Horizontal case.* For Q = (x, y, z, f, f′ : x → y, g, g′ : y → z, α : f ⇒ f′, β : g ⇒ g′), there are three apex edges p_x, p_y, p_z. Strict 2-cells such as p_x ∗₀ (α ∗₀ g) no longer span from the apex to the unique sink in one column.

   Prove RC(3) for either context, using item 11 for the inactive parts, or exhibit two parallel 3-terms with equal strict image and no 4-term between them.
2. **RC(3) for every join context Cone(Q; c).** By item 4 this gives N^cone through dimension 3. Is there an induction on Q, for example on the number of 2-generators, that reuses item 12's normal form "prefix ; generator ; suffix" for each 3-generator in turn?
3. **RC(4) for Cone(D³; c).** This is the first case where the cone has a 4-generator, p_Ω for Ω : α ⇛ α′. By item 4 it would also give RC(3) for Cone(D²; c) again, a consistency check. What replaces the depth-1 naturality used in item 12 when the varying cell is a 3-variable?
4. **RC(n) for join contexts.** Possible routes:
   - induction on Q;
   - the support lemma (item 11) combined with a normal form for terms whose strict image uses each top generator once;
   - a comparison between CaTT's term model and Campion's result that the attachment pushouts of loop-free Steiner complexes stay pushouts in flagged weak (∞,n)-categories (arXiv 2311.00200, Thm 5.11, Rem. 5.13).

## What would count as a solution

Any of the following:
- a proof of RC(3) for either context in Question 1, or for all join contexts;
- a proof of RC(4) for Cone(D³; c), or of RC(n);
- a counterexample: a join context with two parallel terms of equal strict image and no term between them;
- a reference that constructs cones over coherence terms in CaTT or another algebraic presentation of weak ω-categories.

# Research Response

**The vertical case of Question 1 holds.** The argument extends to every finite vertical chain of 2-disks.

Let
\[
Q_m=
\bigl(x,y,\ f_0,\ldots,f_m:x\to y,\ 
\alpha_i:f_{i-1}\Rightarrow f_i\ (1\le i\le m)\bigr).
\]

> **Theorem.** Using the support lemma and the normalisation and fusion construction established in round 3,
> \[
> \boxed{\operatorname{RC}(3,\operatorname{Cone}(Q_m;c))}
> \]
> holds for every finite \(m\).

The two extensions needed beyond round 3 are:

1. the normalisers for the 2-dimensional subcontext work for arbitrary finite vertical words;
2. an arbitrary right 2-whisker of a cone 3-generator can be replaced by its chosen normal form, with a 4-dimensional comparison.

The order of construction matters: first sequentialise the whole 3-term into individual generator insertions, then normalise those insertions. This avoids assuming a fusion theorem for an already normalised composite of several cone 3-generators.

## 1. Notation and strict classification

Write \(\Delta_m=\operatorname{Cone}(Q_m;c)\), and put
\[
\begin{aligned}
a&=p_x,& b&=p_y,\\
F_i&=a*_0f_i,& A_i&=a*_0\alpha_i,\\
u_i&=p_{f_i}:b\Rightarrow F_i,&
M_i&=p_{\alpha_i}:u_i\Rrightarrow u_{i-1}*_1A_i.
\end{aligned}
\]
Let \(K_m\) be the subcontext obtained by deleting all \(M_i\). Thus \(K_m\) has no generators above dimension 2.

Write \(U\simeq_4V\) when there is a 4-term between parallel 3-terms \(U,V\). Every 3-term in \(K_m\), and every 4-term in \(\Delta_m\), is invertible: its support in its own dimension is empty. Consequently \(\simeq_4\) is an equivalence relation and is preserved by composition and whiskering. Here inverses are weak inverses, with their cancellation cells. This is the syntactic invertibility criterion of Benjamin–Markakis, Proposition 35. [arxiv.org](https://arxiv.org/pdf/2406.12127?utm_source=chatgpt.com)

### Strict 2-cells

For this subsection, symbols denote strict images and juxtaposition denotes strict \(*_1\)-composition. Put
\[
R_{ii}=1_{F_i},\qquad
R_{ij}=A_{i+1}\cdots A_j\quad(i<j),
\]
and
\[
W_{ij}=u_iR_{ij}\qquad(i\le j).
\]

The strict 2-cells from \(c\) to \(y\) are exactly
\[
1_b,\qquad R_{ij},\qquad W_{ij}.
\]

Indeed, their directed path expressions are the paths in the graph with edges
\[
u_i:b\longrightarrow F_i,
\qquad
A_i:F_{i-1}\longrightarrow F_i.
\]
A path starting at \(b\) has one initial edge \(u_i\), followed by a consecutive string of \(A\)'s. A path starting at \(F_i\) is a consecutive string of \(A\)'s.

The other nonidentity strict 2-cells are the consecutive composites of the base generators \(\alpha_i\).

### Strict 3-cells

A nonidentity strict 3-cell can only apply an \(M_i\) to the initial \(u_i\) of a word \(W_{ij}\). Its left 2-whisker is an identity, because there is no nonidentity 2-path ending at \(b\). Its right 2-whisker is \(R_{ij}\). Thus the generating steps are
\[
\sigma_i^j=M_i*_1R_{ij}:
W_{ij}\longrightarrow W_{i-1,j},
\qquad 1\le i\le j.
\]

For each fixed \(j\), the rewriting graph is a chain:
\[
W_{jj}\longrightarrow W_{j-1,j}\longrightarrow\cdots
\longrightarrow W_{0j}.
\]

It follows that the nonidentity strict 3-cells are exactly
\[
c^j_{i\ell}:W_{ij}\longrightarrow W_{\ell j},
\qquad 0\le\ell<i\le j,
\]
with generator sequence
\[
i,\ i-1,\ \ldots,\ \ell+1.
\tag{1}
\]

This also accounts for lower-dimensional compositions. Two nonidentity 3-cells cannot compose at level 1: every such cell has initial 1-boundary \(b\), whereas its final 1-boundary is some \(F_j\). At level 0, only point-unit whiskers are possible, since there are no nonidentity arrows into \(c\) or out of \(y\).

In particular, there are no competing orders of generator applications in this family.

### Literal representatives

Return now to raw CaTT terms. Choose right-associated terms
\[
r_{ii}=1_{F_i},\qquad
r_{i,i+1}=A_{i+1},\qquad
r_{ij}=A_{i+1}*_1r_{i+1,j}\quad(j>i+1),
\]
and put
\[
w_{ii}=u_i,\qquad w_{ij}=u_i*_1r_{ij}\quad(i<j).
\]

Choose
\[
S_i^i=M_i.
\]
For \(j>i\), choose the ordinary associator
\[
\mathfrak a:
(u_{i-1}*_1A_i)*_1r_{ij}
\Rrightarrow
u_{i-1}*_1(A_i*_1r_{ij})
\]
and define
\[
S_i^j=(M_i*_1r_{ij})*_2\mathfrak a.
\tag{2}
\]
Then, literally,
\[
S_i^j:w_{ij}\Rrightarrow w_{i-1,j}.
\]

Let \(C^j_{i\ell}\) be a fixed association of
\[
S_i^j*_2S_{i-1}^j*_2\cdots *_2S_{\ell+1}^j.
\tag{3}
\]

The associator in (2) is necessary: the unadjusted target of \(M_i*_1r_{ij}\) has the other bracketing.

## 2. The 2-dimensional subcontext

The first step is
\[
\operatorname{RC}(3,K_m).
\tag{4}
\]

Here is the uniform extension of the round-3 normaliser construction.

### 2.1 Supports that are pasting contexts

The dependency support of a pure base interval is its vertical pasting context. The support of \(R_{ij}\), for \(i<j\), is the pasting context
\[
D^1(a)*_0Q_{[i,j]}.
\]
For \(i=j\), the support is the 1-path \(a,f_i\). Identity 2-cells on other strict 1-paths likewise have path supports.

Therefore the support lemma puts every term with any of these strict images literally in the corresponding pasting context, up to the evident renaming. Parallel full terms there admit direct coherences.

The only remaining strict 2-images are
\[
W_{ij}=u_iA_{i+1}\cdots A_j.
\tag{5}
\]
Their supports need the vertical-column construction.

### 2.2 Factorisation through one vertical column

Consider a 2-coherence whose strict image is (5). Exactly one substituted formal 2-generator has an image using \(u_i\). Its root 0-column spans \(c\to y\).

Every other root 0-column must then have identity strict 1-boundary at \(c\) or at \(y\). By the support lemma, all terms assigned to such a column are literally terms over that endpoint alone.

Rename those point terms at the endpoints of the retained column. This gives the same literal factorisation used in round 3:
\[
C_n\vdash\delta:P,\qquad
K_m\vdash\sigma:C_n,\qquad
\gamma=\delta[\sigma],
\tag{6}
\]
where \(P\) is the original arity and \(C_n\) is a vertical chain of \(n\) 2-generators.

The original head is retained as a term over \(C_n\):
\[
r=\operatorname{coh}_{P,B}[\delta].
\]
No head is replaced merely because its strict image agrees with a composite.

The factorisation is stable under the substitutions used below. Outside the retained column, it performs only endpoint renaming.

### 2.3 Normalisers and common evaluation

For each 1-term \(p\), choose an invertible path comparison
\[
\kappa_p:p\Rightarrow p^0,
\]
where \(p^0\) is the chosen representative of its strict path. For a strict 2-cell \(e\) and literal 1-boundaries \(p,q\), put
\[
\widehat e_{p,q}
=
(\kappa_p*_1e^0)*_1\kappa_q^{-1}.
\]

We construct invertible 3-terms
\[
N_A:A\Rrightarrow\widehat{\pi A}_{p,q}
\qquad(A:p\Rightarrow q)
\tag{7}
\]
by structural recursion on the actual 2-term \(A\).

For the pasting-supported cases of §2.1, use a direct coherence.

For (5), use (6). Write the generators of \(C_n\) as
\[
e_k:z_{k-1}\Rightarrow z_k,
\]
and choose a vertical fold \(L_n\). If the retained full term is \(r:p\Rightarrow q\), choose path comparisons
\[
k_p:p\Rightarrow z_0,\qquad k_q:q\Rightarrow z_n
\]
and put
\[
H_n^B=(k_p*_1L_n)*_1k_q^{-1}.
\]
There is a direct full coherence
\[
\chi_r:r\Rrightarrow H_n^B
\]
over \(C_n\).

After substitution, evaluate \(H_n^B[\sigma]\) by:

1. applying the already constructed \(N_{\sigma(e_k)}\);
2. cancelling the intermediate \(\kappa^{-1}*_1\kappa\) pairs;
3. comparing the resulting external path normalisers with the chosen \(\kappa_{p[\sigma]},\kappa_{q[\sigma]}\);
4. expanding pure intervals into their \(A\)-letters and reassociating the resulting word to \(w_{ij}\).

Call this evaluation \(E(\sigma;B)\). It depends on \(\sigma\) and the literal boundary type \(B\), but not on the full term \(r:B\). Define
\[
N_{r[\sigma]}=\chi_r[\sigma]*_2E(\sigma;B)
\]
when this is the outer-head construction.

Every recursive call in this definition is on an original proper 2-dimensional substitution argument.

### 2.4 Fusion for arbitrary finite words

The fusion statement is
\[
N_{r[\sigma]}
\ \simeq_4\
\chi_r[\sigma]*_2E(\sigma;B)
\tag{8}
\]
for every full formal \(r:B\) over \(C_n\), including when \(r[\sigma]\) was normalised through a different outer-head factorisation.

The proof is structural induction on the **formal** term \(r\).

Each proper formal 2-argument has strict image a consecutive interval of \(e_1,\ldots,e_n\). First restrict it to that interval subcontext using the support lemma. Restriction and renaming preserve the strict decrease in formal term size.

After applying \(\sigma\), these intervals partition the word (5):

- empty intervals have path support;
- intervals not using \(u_i\) have the pasting supports of §2.1;
- exactly one interval uses \(u_i\).

For the first two cases, the competing 3-terms are compared directly by a 4-coherence on their pasting support. Only the last case requires the formal-term induction hypothesis.

The rest of the fusion comparison uses the round-3 operations:

- compare the assembled formal comparison with \(\chi_r\) by a direct 4-coherence over \(C_n\);
- interchange normalisers acting on adjacent 2-letters using pasting arities formed from 3-disks;
- reassociate and cancel intermediate path normalisers;
- compare alternative path comparisons by direct 4-coherences on the actual 1-path.

In particular, one does **not** identify
\[
\kappa_{p[\sigma]}
\quad\text{with}\quad
k_p[\sigma]*_1\kappa_{\sigma(z_0)}
\]
literally. These are compared by a 3-cell on their common path support; alternative such comparisons are compared there by a 4-cell.

After those comparisons, hold the common external \(\kappa\)-frames fixed. The final word comparisons are direct coherences over
\[
C_{j-i+1},
\]
with its generators sent to
\[
u_i,\ A_{i+1},\ldots,A_j.
\]
This is the precise point where the word-length restriction disappears: the arity is a genuine vertical pasting context for every finite \(j-i+1\).

In the formal-variable case, (8) is unitor naturality along the arbitrary 3-normaliser \(N_A\), followed by path comparisons. It varies a 2-variable in a 3-term, so it is within depth-1 naturality. The same depth bound applies to the other naturality operations above. [arxiv.org](https://arxiv.org/pdf/2501.11620?utm_source=chatgpt.com)

### 2.5 Compatibility with 3-terms

We now obtain, for every \(T:A\Rrightarrow B\) in \(K_m\),
\[
T*_2N_B\ \simeq_4\ N_A.
\tag{9}
\]

First take a 3-coherence head of arity at most 2. In a pasting-supported fibre, use a direct 4-coherence. In a fibre (5), factor through \(C_n\). The two formal 3-terms
\[
T^\delta*_2\chi_{\mathrm{target}},

## 3. Sequentialisation with literal boundaries

## 4. Normalising the actual right whisker

\ \simeq_4\
C^j_{i\ell}.
}

Only the individual generator comparison (15) was needed. A compatibility theorem for whiskering a previously normalised multi-generator composite was not used.

## 6. Recovering the original literal boundaries

Let \(U,V:P\Rrightarrow Q\) be parallel with equal strict images.

If their common strict image is an identity, the support lemma puts both terms in \(K_m\), so (4) applies.

Otherwise, their common image is some \(c^j_{i\ell}\). Equation (17), using the same \(\eta_P,\eta_Q\), gives
\[
\mathcal T_j(U)\simeq_4\mathcal T_j(V).
\tag{18}
\]

To undo the fixed path frames, define
\[
G(X)=(L_s^{-1}*_1X)*_1R_t^{-1}.
\]
For every 2-term \(P:s\Rightarrow t\), reassociation, inverse witnesses and unitors give a \(K_m\) 3-term
\[
e_P:G(\mathcal T_j(P))\Rrightarrow P.
\]
Naturality of this 3-term in the 2-variable \(P\) supplies
\[
G(\mathcal T_j(U))*_2e_Q
\ \Longrightarrow\
e_P*_2U,
\tag{19}
\]
and likewise for \(V\). This again has depth 1.

Apply \(G\) to (18), use (19), and cancel the invertible \(e_P,e_Q\). The result is a 4-term between \(U\) and \(V\). This proves the theorem.

## 7. The vertical pair and the scope of the result

For the requested vertical pair, take \(m=2\). Its nonidentity strict 3-cells are exactly:

|---|---|---|
