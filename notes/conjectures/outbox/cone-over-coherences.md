# Cones over coherence terms in CaTT (N^cone)

*A self-contained problem. No knowledge of the project that posed it is assumed. The question is Conjecture N^cone in "Statement"; the smallest open cases are listed at the end.*

## Background

**CaTT.** Contexts list variables `x : A`, where a type is `⋆` or `a →_A b` with a, b terms of type A. Terms are variables or `coh_{Q,B}[γ]`, where Q is a *pasting context* (a context presenting a globular pasting diagram), B is a type over Q satisfying the usual side conditions (either both boundary terms are full in Q, the *coherence case*, or each is full in the matching boundary of Q, the *composition case*), and `γ : Δ ⊢ Q` is a substitution. Reference: Finster–Mimram, *A type-theoretical definition of weak ω-categories* (LICS 2017); Benjamin–Finster–Mimram, *Globular weak ω-categories as models of a type theory* (2021). Composition order below is diagrammatic, and `u ∗_k w` denotes the binary composite along a k-cell, which is itself a composition coherence over two disks glued along a k-disk. For a term t of dimension m ≥ 1 write `σt, τt` for its source and target, and `σʲt` for the iterated source.

**Cone over a globular context.** Call a context *globular* if every variable's type is `⋆` or `a → b` with a, b variables; every pasting context is globular. For globular Γ, the *specified cone* `Cone(Γ; c)` extends Γ by an object `c : ⋆` and one variable `p_t` for each variable t of Γ, in order:

```
p_x : c → x                                                   (dim x = 0)
p_t : p_{τt}  →  p_{σt} ∗_{m−1} (p_{σ²t} ∗_{m−2} ( … (p_{σᵐt} ∗₀ t)))      (dim t = m ≥ 1)
```

So `f : x → y` gets `p_f : p_y ⇒ p_x ∗₀ f`, and `α : f ⇒ g` gets `p_α : p_g ⇛ p_f ∗₁ (p_x ∗₀ α)`. This is a well-formed context for every globular Γ (by induction on the variables: each composite in the target is well formed because the projections of the boundary variables already have the matching types). It is the cone of T. J. Mikhail's Thm 3.3 (*A type-theoretic definition of lax (∞,∞)-limits*, arXiv 2412.13310), lax at the vertices. When Γ is a pasting context, the strict ω-category freely generated by `Cone(Γ; c)` is the Ara–Maltsiniotis join `c ⋆ Γ`, with `p_t ↦ c ⋆ t`.

**Cones over arbitrary contexts.** In a general context a variable may have composite boundaries, e.g. `τ : f ∗₀ g ⇒ h`. The cone variable over τ then needs a cone cell `P(f ∗₀ g)` over the *term* `f ∗₀ g`. Extend p from variables to all terms:

```
P(x)              := p_x
P(coh_{Q,B}[γ])   := Π(Q, B)[Cone(γ)]
```

where `Cone(γ) : Cone(Γ; c) ⊢ Cone(Q; c)` sends `q ↦ γ(q)`, `c ↦ c`, `p_q ↦ P(γ(q))`, and `Π(Q, B)` is a chosen term of `Cone(Q; c)`. For a term t of dimension m ≥ 1 put

```
T(t) := P(σt) ∗_{m−1} (P(σ²t) ∗_{m−2} ( … (P(σᵐt) ∗₀ t))).
```

For `c₀ := coh_{Q,B}[id_Q]`, of dimension n, the term `Π(Q, B)` must have type

```
Π(Q, B) : P(τc₀) → T(c₀)          (an (n+1)-term of Cone(Q; c)).
```

This type is well formed once P is defined on the boundary terms of c₀, which have dimension < n. So the definition is a recursion on dimension. Within a dimension, the boundary terms of an n-coherence may themselves contain n-dimensional subterms only in the composition case, through lower-dimensional factors, so the recursion is well founded with the order "lower dimension first, then structural" .

## Statement

> **Conjecture N^cone.** For every pasting context Q and every type B such that `coh_{Q,B}` is a valid coherence, there is a term `Π(Q, B)` of `Cone(Q; c)` of type `P(τc₀) → T(c₀)`, where P on the boundary of c₀ is defined from Π at lower dimensions as above. Moreover Π can be chosen so that, in the free strict ω-category on `Cone(Q; c)`, `π(Π(Q, B)) = c ⋆ π(c₀)` (the join of c with the strict image of c₀).

The strict-image clause is part of the statement because the inductive step uses it: it guarantees that `P(u)` has strict image `c ⋆ π(u)` for every term u.

Consequence: for every CaTT context Γ, the extension `Cone(Γ; c)` (with P in place of p in the types of the cone variables) is a well-formed context. This is a precise form of Mikhail's Conjecture 3.6 ("cones exist over arbitrary contexts"), restricted to a specified construction.

## What is known

1. **Dimension 1 (proved).** For the identity coherence over a point, `Π := ` the coherence `p_x ⇒ p_x ∗₀ id_x` over `(c, x, p_x)`. For the composite of a chain `x₀ —f₁→ … —f_m→ x_m`,
   ```
   Π := p_{f_m} ∗₁ ((p_{f_{m−1}} ∗₀ f_m) ∗₁ ( … ((p_{f_1} ∗₀ f_2) ∗₀ …) ∗₀ f_m)) ∗₁ κ
   ```
   with κ the coherence over `c → x₀ → … → x_m` from the left-nested composite to `p_{x₀} ∗₀ comp(f)`. This has been machine-checked with a certified CaTT type checker on `τ : f ∗₀ g ⇒ h`.

2. **Coherence case reduces to relative coherence.** Let c₀ be a coherence-case coherence (`π(c₀)` is an identity). Then `π(T(c₀)) = π(P(σc₀))`, and by the strict-image clause at lower dimension `π(P(σc₀)) = c ⋆ π(σc₀) = c ⋆ π(τc₀) = π(P(τc₀))`. So `P(τc₀)` and `T(c₀)` are parallel n-terms with equal strict images, and Π is exactly an instance of
   > **RC(n) for Δ.** Any two parallel n-terms of Δ with equal strict images are connected by an (n+1)-term,

   for `Δ = Cone(Q; c)`. RC(2) holds in every CaTT context (an unpublished paper proof by the posers, not yet independently checked: it sequentialises both terms into whiskered generators and connects them by exchange moves). So the coherence case of N^cone holds in dimension 2, conditionally on that proof.

3. **Composition case.** Here `π(c₀)` is a non-identity cell, and Π must be built from the cone generators. Every cell of the free strict ω-category on a computad is the image of some CaTT term (a formal composite of generators), so there is a term W with `π(W) = c ⋆ π(c₀)`. Its weak boundary need not be `P(τc₀) → T(c₀)`; it only has the same strict image. Correcting it needs connecting cells between terms of equal strict image in every dimension ≤ n, assembled by the "transport along an invertible sphere" step. Dimension 1 is item 1 above, done by hand. In dimension 2 the vertical composite is elementary: for `c₀ = α ∗₁ β` with `α : f ⇒ g`, `β : g ⇒ h`, take `p_β`, then `p_α ∗₁ (p_x ∗₀ β)`, then an associator, then `p_f ∗₁ δ` with δ the coherence `(p_x ∗₀ α) ∗₁ (p_x ∗₀ β) ⇛ p_x ∗₀ (α ∗₁ β)` over the pasting context `(c, x, p_x, y, f, g, h, α, β)`. **The horizontal composite `α ∗₀ β`, and composites in general, are not yet written out.**

4. **Relation to Conjecture N.** The companion Conjecture N (naturality: for a coherence over a pasting context Q and an up-closed set Y of its variables, a cell between the two pastings of the coherence with the cylinder over Y, in the context `Q↑Y` presenting the partial cylinder) asks for naturality cells `t↑` in cylinder contexts `Q↑Y`. N^cone asks for cells in join contexts `Cone(Q; c)`. Both are relative-coherence statements for a context that is not a pasting context but whose strict counterpart is a free ω-category on a loop-free basis (`Q ⊗ D¹` and `c ⋆ Q`). In both, RC(n) for that context gives the coherence case directly. Neither is known to imply the other. The join `c ⋆ Q` is the cylinder `D¹ ⊗ Q` with its source end collapsed to a point (Ara–Maltsiniotis), so a construction for N on the full cylinder followed by contraction along units would give the coherence case of N^cone. That needs units in place of a strict quotient, which is the obstacle.

5. **Strict case.** In strict ω-categories, the join `c ⋆ Q` exists for every pasting diagram Q, and c ⋆ − is functorial on cells (Ara–Maltsiniotis, *Joint et tranches pour les ∞-catégories strictes*, Mém. SMF 165, 2020). So the strict analogue of N^cone holds in every dimension.

## Why it matters

A type theory of weak ω-categories with limits needs a cone over every diagram, and a diagram is a context. If the type theory only states a judgment "this is a cone", it admits cones that are not the canonical one, and the universal property breaks (Mikhail's printed rules do: over a loop, a cone can reuse one projection for two cells). The fix is to *construct* the cone as a function of the diagram. For diagrams made of plain generators this construction is elementary. For diagrams whose cells have composite boundaries (a 2-cell from a composite `f ∗₀ g` to h, say) it needs a cone cell over each coherence, which is this conjecture. A proof makes the limit rules apply to every diagram rather than only to "globular" ones.

## Smallest open cases

1. **Dimension 2, composition case, horizontal.** Q = `x —f→ y —f′→ z` with `α : f ⇒ g`, `β : f′ ⇒ g′`, and `c₀ = α ∗₀ β : f ∗₀ f′ ⇒ g ∗₀ g′`. Required: a 3-term `P(g ∗₀ g′) ⇛ P(f ∗₀ f′) ∗₁ (p_x ∗₀ (α ∗₀ β))` in `Cone(Q; c)`, with P on 1-dimensional composites as in "What is known" (1). (The vertical case `α ∗₁ β` is easy: paste `p_β`, `p_α` whiskered, an associator, and the coherence `(p_x ∗₀ α) ∗₁ (p_x ∗₀ β) ⇛ p_x ∗₀ (α ∗₁ β)`, which lives over a pasting context.)
2. **Dimension 3, coherence case.** Q = D² (`x, y, f, g, α : f ⇒ g`), and `c₀ : α ⇛ α ∗₁ 1_g` the unitor. Required: a 4-term `P(α ∗₁ 1_g) → P(α) ∗₂ (p_f ∗₁ (p_x ∗₀ c₀))` in `Cone(D²; c)`. By "What is known" (2), this is RC(3) for this one context, which is not a pasting context.
3. **The general reduction.** Show that RC(n) for the join contexts `Cone(Q; c)` (all pasting contexts Q) implies N^cone in dimension n, including the composition case. Equivalently, carry out the boundary transport of "What is known" (3) in general.

## What would count as a solution

A proof of N^cone, or of any of the three cases above; a counterexample; or a reference that constructs joins with a point (cones) over coherence terms in CaTT or another algebraic presentation of weak ω-categories.
