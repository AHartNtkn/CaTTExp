# Cones over coherence terms in CaTT (N^cone), round 2

*A self-contained problem. No knowledge of the project that posed it is assumed. Round 1 and its verified answer are in `answered/cone-over-coherences-2026-11-18.md`. Questions are at the end, smallest first.*

## Background

**CaTT.** Contexts list variables `x : A`, where a type is `⋆` or `a →_A b` with a, b terms of type A. Terms are variables or `coh_{Q,B}[γ]`, where Q is a *pasting context* (a context presenting a globular pasting diagram), B is a type over Q satisfying the usual side conditions (either both boundary terms are full in Q, the *coherence case*, or each is full in the matching boundary of Q, the *composition case*), and `γ : Δ ⊢ Q` is a substitution. Reference: Finster–Mimram, *A type-theoretical definition of weak ω-categories* (LICS 2017); Benjamin–Finster–Mimram, *Globular weak ω-categories as models of a type theory* (2021). Composition order below is diagrammatic, and `u ∗_k w` denotes the binary composite along a k-cell, which is itself a composition coherence over two disks glued along a k-disk. For a term t of dimension m ≥ 1 write `σt, τt` for its source and target, and `σʲt` for the iterated source.

**Cone over a globular context.** Call a context *globular* if every variable's type is `⋆` or `a → b` with a, b variables; every pasting context is globular. For globular Γ, the *specified cone* `Cone(Γ; c)` extends Γ by an object `c : ⋆` and one variable `p_t` for each variable t of Γ, in order:

```
p_x : c → x                                                   (dim x = 0)
p_t : p_{τt}  →  p_{σt} ∗_{m−1} (p_{σ²t} ∗_{m−2} ( … (p_{σᵐt} ∗₀ t)))      (dim t = m ≥ 1)
```

So `f : x → y` gets `p_f : p_y ⇒ p_x ∗₀ f`, and `α : f ⇒ g` gets `p_α : p_g ⇛ p_f ∗₁ (p_x ∗₀ α)`. This is a well-formed context for every globular Γ (by induction on the variables: each composite in the target is well formed because the projections of the boundary variables already have the matching types). It is the cone of T. J. Mikhail's Thm 3.3 (*A type-theoretic definition of lax (∞,∞)-limits*, arXiv 2412.13310), lax at the vertices. When Γ is a pasting context, the strict ω-category freely generated by `Cone(Γ; c)` is the Ara–Maltsiniotis join `c ⋆ Γ`, with `p_t ↦ c ⋆ t`.

**Cones over arbitrary contexts.** In a general context a variable may have composite boundaries, e.g. `τ : f ∗₀ g ⇒ h`. The cone variable over τ then needs a cone cell `P(f ∗₀ g)` over the *term* `f ∗₀ g`. Extend p from variables to all terms:

```
P(x)              := p_x
P(coh_{Q,B}[γ])   := Π(Q, B)[Cone(γ)]
```

where `Cone(γ) : Cone(Γ; c) ⊢ Cone(Q; c)` sends `q ↦ γ(q)`, `c ↦ c`, `p_q ↦ P(γ(q))`, and `Π(Q, B)` is a chosen term of `Cone(Q; c)`. For a term t of dimension m ≥ 1 put

```
T(t) := P(σt) ∗_{m−1} (P(σ²t) ∗_{m−2} ( … (P(σᵐt) ∗₀ t))).
```

For `c₀ := coh_{Q,B}[id_Q]`, of dimension n, the term `Π(Q, B)` must have type

```
Π(Q, B) : P(τc₀) → T(c₀)          (an (n+1)-term of Cone(Q; c)).
```

This type is well formed once P is defined on the boundary terms of c₀, which have dimension < n. So the definition is a recursion on dimension. Within a dimension, the boundary terms of an n-coherence may themselves contain n-dimensional subterms only in the composition case, through lower-dimensional factors, so the recursion is well founded with the order "lower dimension first, then structural" .

## Statement

> **Conjecture N^cone.** For every pasting context Q and every type B such that `coh_{Q,B}` is a valid coherence, there is a term `Π(Q, B)` of `Cone(Q; c)` of type `P(τc₀) → T(c₀)`, where P on the boundary of c₀ is defined from Π at lower dimensions as above. Moreover Π can be chosen so that, in the free strict ω-category on `Cone(Q; c)`, `π(Π(Q, B)) = c ⋆ π(c₀)` (the join of c with the strict image of c₀).

The strict-image clause is part of the statement because the inductive step uses it: it guarantees that `P(u)` has strict image `c ⋆ π(u)` for every term u.

Consequence: for every CaTT context Γ, the extension `Cone(Γ; c)` (with P in place of p in the types of the cone variables) is a well-formed context. This is a precise form of Mikhail's Conjecture 3.6 ("cones exist over arbitrary contexts"), restricted to a specified construction.

## What is known

1. **Dimension 1 (proved).** For the composite of a chain `x₀ —f₁→ … —f_m→ x_m`, Π is the vertical composite of the whiskered cone generators `p_{f_m}`, `p_{f_{m−1}} ∗₀ f_m`, … followed by the associator coherence κ over `c → x₀ → … → x_m`. Machine-checked on `τ : f ∗₀ g ⇒ h`.

2. **Every relative-coherence witness in a join context strictifies to an identity (round 1, proved).** The free strict ω-category on `Cone(Q; c)` is the join `c ⋆ Q`. This join is ν(K) for a strong Steiner complex K, because joins of strong Steiner complexes are strong Steiner (Ara–Maltsiniotis, *Joint et tranches*). In a strong Steiner complex every positive cycle is zero: take a minimal basis element b of its support and a ∈ supp ∂⁻b; only a b′ with a ∈ supp ∂⁺b′ could cancel a, and that b′ would satisfy b′ < a < b. So every endo-cell of c ⋆ Q is an identity.

3. **Reduction to relative coherence (round 1, proved).** Write **RC(r) for Δ** for the statement: any two parallel r-terms of Δ with equal strict images are connected by an (r+1)-term. Then:

   > If RC(1), …, RC(n) hold for `Cone(Q; c)` for every pasting context Q, then N^cone holds through dimension n, in both the coherence case and the composition case.

   Proof.
   - RC(1..n) lift every strict (n+1)-cell to a term. Lift generators, identities and binary composites, inserting RC corrections to make the gluings literal; by item 2 those corrections strictify to identities.
   - A transport lemma then corrects the r-faces of the lift one dimension at a time, using (λ_r ∗_r W) ∗_r ρ_r with λ_r, ρ_r from RC(r). The strict image is unchanged, and no correction is inverted.
   - Applied to `d = c ⋆ π(c₀)`, this gives `Π(Q, B) : P(τc₀) → T(c₀)` with `π(Π) = c ⋆ π(c₀)`.

4. **Dimension 2 holds (proved).** RC(1) holds in every CaTT context: parallel 1-terms with the same strict path pull back to the chain context of that path. RC(2) holds in every CaTT context (paper proof: sequentialise both 2-terms into whiskered 2-generators and connect them by exchange moves, each a coherence over "chain, 2-disc, chain, 2-disc, chain"). So item 3 gives N^cone in dimension 2. There is also an explicit term for the horizontal composite `α ∗₀ β` that uses no RC: a chain of eight 3-cells built from p_β, p_α ∗₀ g′, a whiskering-distribution coherence, an exchange coherence, a coherence over the pasting context `c → x ⇒ y ⇒ z`, and reassociations. Its strict image is `p_β ∗₁ (p_α ∗₀ g′) = c ⋆ (α ∗₀ β)`.

5. **A related case that is settled.** Relative coherence in dimension 3 is known for one context that is not a pasting context: the lax square, with objects x⁻, x⁺, y⁻, y⁺, edges x↑, y↑, f⁻, f⁺ and one 2-cell F : f⁻ ∗₀ y↑ ⇒ x↑ ∗₀ f⁺. RC(3) holds there. The proof:
   - For a 2-term with strict image F, exactly one 0-column of its arity carries F and spans x⁻ → y⁺. Every other column sits at the point x⁻ or y⁺ and factors literally through a point context.
   - This factorisation is stable under substitution.
   - It gives normalisers T → (κ · F) · κ′ that are compatible with every 3-term, by induction on syntax.
   
   The step that uses the square is that x⁻ is the unique source and y⁺ the unique sink, so the discarded columns are point-supported. In `c ⋆ Q` the apex c is the unique source object, but there is in general more than one sink.

6. **Strict case.** In strict ω-categories, `c ⋆ −` is functorial on cells (Ara–Maltsiniotis), so the strict analogue of N^cone holds in every dimension.

7. **What is not enough.** Loopy contexts can fail RC(3): in (x, a : 1_x → 1_x) the weak free object groupoidifies to S² and the strict one to K(ℤ, 2). So a proof must use the loop-freeness of `c ⋆ Q`.

## Questions

1. **RC(3) for the smallest join context, Cone(D²; c).** Here D² = (x, y, f, g, α : f ⇒ g). The first instance is the unitor `c₀ : α ⇛ α ∗₁ 1_g`, for which a 4-term `P(α ∗₁ 1_g) → P(α) ∗₂ (p_f ∗₁ (p_x ∗₀ c₀))` is required. Then prove RC(3) for `Cone(D²; c)` in general. Does an active-column factorisation as in item 5 work, with the apex c in the role of the unique source?
2. **RC(3) for every join context Cone(Q; c), Q a pasting context.** By item 3 this gives N^cone in dimension 3. Which property of `c ⋆ Q` does the proof use?
3. **RC(n) for join contexts**, or a direct construction of `Π(Q, B)` in all dimensions, for example by induction on Q using the join's decomposition `c ⋆ (Q ∨ Q′)`, or via the cylinder `D¹ ⊗ Q` contracted at its source end with weak units in place of a strict quotient.
4. **Fixed dimension.** Does RC(n) for all join contexts imply RC(r) for all r < n there? (Item 3 needs RC in every dimension up to n.)

## What would count as a solution

Explicit terms for question 1; a proof of RC(3) or RC(n) for join contexts; a counterexample (a join context with two parallel terms of equal strict image and no term between them); or a reference that constructs cones over coherence terms in CaTT or another algebraic presentation of weak ω-categories.
