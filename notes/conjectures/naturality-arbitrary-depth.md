## 1. Background: the type theory CaTT

CaTT (Finster–Mimram, LICS 2017) is a dependent type theory whose models are weak ω-categories. This section fixes the syntax used below, following Benjamin–Markakis–Offord–Sarti–Vicary (BMOSV, arXiv 2501.11620, §2).

### 1.1 Syntax

```
Types          A, B  ::=  ⋆  |  u →_A v
Terms          t, u  ::=  x  |  coh_{Γ,A}[γ]
Contexts       Γ, Δ  ::=  ∅  |  Γ, x : A
Substitutions  γ     ::=  ⟨⟩ |  ⟨γ, x ↦ t⟩
```

`⋆` is the type of 0-cells. `u →_A v` is the type of cells from u to v, where u and v have type A. We write `u → v` when A is clear. The dimension of a type is `dim ⋆ = −1` and `dim(u →_A v) = dim A + 1`. A term of type A has dimension `dim A + 1`.

For a term `t : u → v`, write `σ(t) := u` and `τ(t) := v` (source and target), and `σᵏ`, `τᵏ` for their iterates. By globularity, `σ(σ t) = σ(τ t)` and `τ(σ t) = τ(τ t)`, so `σᵏ` and `τᵏ` are unambiguous for k ≥ 2 up to choice of the last step. `Var(t)` and `Var(A)` are the free variables, and `Var(t : A) = Var(t) ∪ Var(A)`.

### 1.2 Pasting contexts

A **pasting context** is a context presenting a globular pasting diagram. The judgment `Γ ⊢ps` is generated by Finster–Mimram's rules:

```
(pss)  x : ⋆ ⊢ps x : ⋆
(pse)  Γ ⊢ps x : A   ⟹   Γ, y : A, f : x →_A y ⊢ps f : x →_A y
(psd)  Γ ⊢ps f : x →_A y   ⟹   Γ ⊢ps y : A
(ps)   Γ ⊢ps x : ⋆   ⟹   Γ ⊢ps
```

In a pasting context, the source and target of every variable are variables. A pasting context Γ has a source boundary `∂⁻Γ` and a target boundary `∂⁺Γ`, which are again pasting contexts (Finster–Mimram; BMOSV §2).

### 1.3 The coherence rule

```
 Γ ⊢ps     Γ ⊢ u →_A v     Δ ⊢ γ : Γ        (+ side condition)
───────────────────────────────────────────────────────────────
              Δ ⊢ coh_{Γ, u→_A v}[γ] : (u →_A v)[γ]
```

The side condition is one of the following.

- **Coherence:** `Var(u : A) = Var(Γ) = Var(v : A)`.
- **Composition:** `∂⁻Γ ⊢ u : A` with `Var(u : A) = Var(∂⁻Γ)`, and `∂⁺Γ ⊢ v : A` with `Var(v : A) = Var(∂⁺Γ)`.

A type satisfying one of these conditions is called **full** in Γ. Every term of CaTT is a variable or of the form `coh_{Γ,A}[γ]`, and typing derivations are unique.

### 1.4 Composites and whiskering

For a pasting context Γ, the **unbiased composite** `comp_Γ` is defined by `comp_Γ = x` if Γ is a disc with top variable x, and otherwise `comp_Γ = coh_{Γ, comp_{∂⁻Γ} → comp_{∂⁺Γ}}[id]` (BMOSV Def. 2.1).

For a p-cell u and a q-cell v with `∂⁺_k u = ∂⁻_k v` for some `k < min(p, q)`, write `u ∗_k v` for the composite over the pasting context of a p-disc and a q-disc glued along a k-disc. When `p ≠ q` this is a **whiskering**. The boundary of a binary composite is computed componentwise:

- `∂⁻_j(u ∗_k v) = ∂⁻_j u ∗_k ∂⁻_j v` and `∂⁺_j(u ∗_k v) = ∂⁺_j u ∗_k ∂⁺_j v` for `j > k`, where a factor of dimension ≤ j is left unchanged.
- `∂⁻_k(u ∗_k v) = ∂⁻_k u` and `∂⁺_k(u ∗_k v) = ∂⁺_k v`.

These equations hold syntactically in CaTT.

## 2. Up-closed sets and the cylinder context

### 2.1 Up-closed sets and depth

Let Γ be a context. A set `Y ⊆ Var(Γ)` is **up-closed** if whenever `y ∈ Y` occurs in the type of a variable x, then `x ∈ Y`.

Following BMOSV §3.1, the **depth** of Y in a term `t : A` is

```
depth_Y(t) = max { dim t − dim y : y ∈ Var(t : A) ∩ Y }
```

and the depth of Y in a context Γ is the maximum depth over its variables. For example, if Y contains a 0-cell and t is a 2-cell using it, then `depth_Y(t) ≥ 2`.

### 2.2 The cylinder types

Fix a pasting context P and an up-closed `Y ⊆ Var(P)`. Suppose that for every term w of P of dimension less than n with `Var(w) ∩ Y ≠ ∅` we already have a term `w↑` (its "cylinder") in a context `P↑Y` defined below, together with the two copies `w⁻` and `w⁺` of w. Put the convention

> if `Var(w) ∩ Y = ∅`, then `w⁻ = w⁺ = w`, and every composite factor `w↑` below is **omitted**.

For a term t of dimension `n ≥ 1`, define two n-cells:

```
a_t  :=  ( … ((t⁻ ∗₀ (τⁿ t)↑) ∗₁ (τⁿ⁻¹ t)↑) … ) ∗_{n−1} (τ t)↑

b_t  :=  (σ t)↑ ∗_{n−1} ( … ((σⁿ⁻¹ t)↑ ∗₁ ((σⁿ t)↑ ∗₀ t⁺)) … )
```

For a 0-cell t, set `a_t := t⁻` and `b_t := t⁺`.

In words: `a_t` is the copy t⁻ followed by the cylinders of its iterated targets, one per dimension. `b_t` is the cylinders of its iterated sources followed by the copy t⁺. For n = 1 this is the familiar lax naturality square:

```
a_t = t⁻ ∗₀ (τ t)↑ ,     b_t = (σ t)↑ ∗₀ t⁺ .
```

For n = 2 and `t : f ⇒ h` with `f, h : x → z`:

```
a_t = (t⁻ ∗₀ z↑) ∗₁ h↑ ,     b_t = f↑ ∗₁ (x↑ ∗₀ t⁺) .
```

**Lemma 1 (well-typedness).** If every `w↑` for lower-dimensional w has type `a_w → b_w`, then `a_t` and `b_t` are well-typed n-cells and

```
a_t, b_t  :  a_{σt} → b_{τt}.
```

*Proof sketch.* Composability of each step in `a_t`: the j-dimensional target of the partial composite is `(… (w⁻ ∗₀ (τʲ w)↑) … ∗_{j−1} (τ w)↑) = a_w`, where `w = τⁿ⁻ʲ t`. This uses the boundary equations of §1.4 and `τᵏ(τⁿ⁻ʲ t) = τⁿ⁻ʲ⁺ᵏ t`. That target is exactly the source of the next factor `w↑ : a_w → b_w`. The case of `b_t` is dual. For the type, the source of `a_t` is computed componentwise and equals `a_{σt}`, using `τᵏ(σ t) = τᵏ⁺¹ t`. The target of `a_t` is the target of its last factor, `b_{τt}`. The case of `b_t` is dual. ∎

When `depth_Y(t) ≤ 1`, all factors `(τᵏ t)↑` and `(σᵏ t)↑` with k ≥ 2 are omitted, and these types coincide with the types `(u → v) ↑_t X` of BMOSV §3.2(3).

### 2.3 The cylinder context P↑Y

For a pasting context P and up-closed Y, the context `P↑Y` is obtained by going through P in order.

- A variable `x ∉ Y` is kept as `x : A_x`. Its type contains no variable of Y, by up-closure.
- A variable `x ∈ Y` of type `A_x` is replaced by three variables:

  ```
  x⁻ : A_x[in⁻],     x⁺ : A_x[in⁺],     x↑ : a_x → b_x
  ```

  where `in^±` rename each `y ∈ Y` to `y^±`.

Because P is a pasting context, every iterated source and target of a variable is a variable. So `a_x` and `b_x` involve only variables of `P↑Y` and binary composites, and Lemma 1 shows `P↑Y` is a well-formed context. It is not a pasting context in general.

**Example.** For `P = (x : ⋆, y : ⋆, f : x → y)` and `Y = Var(P)`, `P↑Y` is the lax square

```
x⁻, x⁺, x↑ : x⁻ → x⁺,  y⁻, y⁺, y↑ : y⁻ → y⁺,
f⁻ : x⁻ → y⁻,  f⁺ : x⁺ → y⁺,  f↑ : f⁻ ∗₀ y↑ → x↑ ∗₀ f⁺ .
```

## 3. The conjecture

Define the naturality terms `t↑` for terms t of P by recursion on dimension and on the structure of t:

- for a variable `x ∈ Y`: `x↑ := x↑` (the variable of P↑Y);
- for `t = coh_{Q,B}[γ]` with `P ⊢ γ : Q`: `t↑ := K(Q, B, γ⁻¹Y)[γ↑]`,

where `γ⁻¹Y = {q ∈ Var(Q) : Var(q[γ]) ∩ Y ≠ ∅}` (which is up-closed in Q), and `γ↑ : P↑Y → Q↑γ⁻¹Y` sends `q⁻ ↦ q[γ]⁻`, `q⁺ ↦ q[γ]⁺`, `q↑ ↦ (q[γ])↑`, and `q ↦ q[γ]` for `q ∉ γ⁻¹Y`.

The recursion is well founded, because the boundary terms of `coh_{Q,B}` have lower dimension. Its only non-syntactic ingredient is the family of terms `K`:

> **Conjecture N.** For every pasting context Q, every type B full in Q, and every non-empty up-closed set `Y ⊆ Var(Q)`, the type
>
> ```
> a_c  →  b_c,      where c = coh_{Q,B}[id_Q],
> ```
>
> is inhabited in `Q↑Y`. Here the factors `w↑` in `a_c` and `b_c` are the naturality terms of the boundary terms w of c, given by the recursion above.

Call a chosen inhabitant `K(Q, B, Y)`.

**Lemma 2 (substitution).** Assuming Conjecture N in dimensions below n, the substitution `γ↑` is well typed. Hence `t↑ : a_t → b_t` for every term t of dimension n.

*Correction (verified 2026-11-18, see the end of this file).* As written, the induction order is wrong. When c is a composite, a top-dimensional variable q of its arity Q has `dim q[γ] = n`, so `γ↑` needs the dimension-n term `(q[γ])↑`, not only lower-dimensional ones. The correct order is: build the dimension-n cylinder types from lower-dimensional lifts; supply the fillers K in dimension n; then define dimension-n term and substitution lifts by structural induction on the term. Same-dimensional arguments of a substitution are proper subterms, so this is well founded.

*Proof sketch.* Each variable `q↑` of `Q↑γ⁻¹Y` has type `a_q → b_q`, built from variables by binary composites. Applying `γ↑` gives the corresponding expression with `(q'[γ])↑` in place of `q'↑`. That is `a_{q[γ]} → b_{q[γ]}`, because binary composites commute with substitution, and because `Var(q') ∩ γ⁻¹Y = ∅` exactly when `Var(q'[γ]) ∩ Y = ∅`, so the same factors are omitted on both sides. ∎

**Consequence (any context).** Conjecture N, together with Lemma 2 and induction on the length of the context, gives a well-formed cylinder context `Γ↑X` and naturality terms `t↑ : a_t → b_t` for every CaTT context Γ (not only pasting contexts), every up-closed X, and every term t. For a variable x whose boundary terms are composites, the type `a_x → b_x` of x↑ uses the naturality terms of those composites.

## 4. Known cases

1. **Depth 0** (`depth_Y(Q) = 0` and `depth_Y(c) = 0`). Then `Q↑Y` is a pasting context, and K is a coherence over it (Benjamin, PhD thesis 2020, §3.4, functoriality; BMOSV Theorem 3.1, case d = k = 0). BMOSV Lemma B.10 adds context depth 0 with term depth 1. Context depth 0 with term depth ≥ 2 is *not* covered by either result. (Corrected 2026-11-18: an earlier version claimed all of context depth 0.)
1a. **Fully selected chains, any 2-dimensional coherence** (`dim Q = 1`, `Y = Var(Q)`, depth 2). Settled by the relative ladder theorem in the researcher response below (verified 2026-11-18). This covers the associator and the left unitor.
2. **Depth at most 1 in both context and term** (`depth_Y(Q) ≤ 1` and `depth_Y(c) ≤ 1`). This is BMOSV Theorem 3.1. The term is built as a composite `j⁻ ∗ c' ∗ j⁺`, where c' is the depth-0 naturality term pulled back along a substitution θ that absorbs the depth-1 cylinders into the depth-0 duplicates. `j^±` are coherences interchanging composites (BMOSV §3.2(6)).
3. **Globular contexts, full Y, conical variant.** Mikhail (arXiv 2412.13310, Theorems 3.3 and 4.4) constructs the analogous contexts (cones over a context, and the Gray cylinder `Γ ⊗ D¹`) when every boundary of every variable is a variable. This is the context-level statement for pasting contexts. It does not provide the terms K.

So the **open case** is: depth of Y in the coherence c is at least 2.

## 5. Evidence: the strict case

In strict ω-categories, the Gray tensor product exists and is monoidal closed (Crans 1995; Ara–Maltsiniotis 2020). For the free strict ω-category on a pasting diagram P, Steiner's theory of loop-free bases (Steiner 2004) presents `P ⊗ I` as the free strict ω-category on the generators `x ⊗ 0`, `x ⊗ 1` and `x ⊗ I`, for x a generator of P. Those are exactly `x⁻`, `x⁺` and `x↑` in `P↑Var(P)`.

The image of any cell c of P under `− ⊗ I` is a cell `c ⊗ I` whose source and target are the strict pastings that `a_c` and `b_c` describe, up to choice of orientation convention. (With Steiner's sign convention `∂(a ⊗ b) = ∂a ⊗ b + (−1)^{|a|} a ⊗ ∂b`, the formulas for `a_x → b_x` match `I ⊗ P`, not `P ⊗ I`; see the verification at the end.) So the strict analogue of Conjecture N holds for every depth. The weak case is open because `Q↑Y` is not a pasting context, so the coherence rule cannot be applied directly.

In the homotopy theory of weak ω-categories, `Q↑Var(Q)` for all Q would be the directed half of a path-object construction. It is not a path object by itself: for C = [1], the constant map C → Fun([1], C) ≅ [2] misses the middle functor, so it is not an equivalence. An invertible or marked variant is needed (corrected 2026-11-18). BMOSV (§1) note that such a construction has long been sought as the missing piece of a model structure on weak ω-categories, analogous to the folk model structure on strict ω-categories (Lafont–Métayer–Worytkiewicz 2010).

## 6. What has been tried

1. **Extending BMOSV's reduction to depth 2.** BMOSV handle depth 1 by sending each depth-0 duplicate `a⁻` to a whiskered composite `a⁻ ∗ (cylinders one dimension down)` (the substitution θ), and closing the gap with interchange coherences `j^±` that live over a pasting sub-shape.
   - At depth 2, θ would need to absorb cylinders from two dimensions down, via nested whiskerings as in `a_t`.
   - The correction terms then have to interchange whiskerings across two dimensions at once. It has not been checked whether the source and target of these corrections lie in a pasting sub-context of `Q↑Y`, which is what is needed to obtain them by the coherence rule.
2. **Peeling Y one stratum at a time.** Naturality with respect to `Y` cannot be obtained as naturality with respect to the arrows in Y followed by naturality with respect to the objects. The set of objects in Y is not up-closed, and iterating ↑ produces `P ⊗ I ⊗ I` rather than `P ⊗ I`.
3. **Embedding Q↑Y in a pasting context.** If `Q↑Y` were a sub-context of a pasting context, K could be obtained by the coherence rule there and restricted. This fails already for the lax square. The 0-cells of a pasting context are linearly ordered by its 1-cells, but in the square `x⁺` and `y⁻` are incomparable. Any proof has to build K as a composite of coherences over pasting sub-shapes, as BMOSV do at depth 1.

### Partial progress: the left unitor at depth 2

The first case outside BMOSV's theorem can be settled by a "sliding" argument. It uses two facts.

- **(F1) Parallel full terms are connected.** If s and t are parallel terms over a pasting context P, and `Var(s : A) = Var(P) = Var(t : A)`, then the coherence rule gives a cell `s → t` over P. Substituting gives such a cell wherever P maps.
- **(F2) Coherences are natural in their top-dimensional arguments.** If x is a top-dimensional variable of a pasting context P, then `{x}` has depth 0 in P. So `P↑{x}` is a pasting context and K exists by the coherence rule (case 1 of §4). Substituting the disc around x by any cell with composite boundaries gives naturality with respect to that cell.

**Instance.** Take `Q = (x : ⋆, y : ⋆, f : x → y)`, `Y = Var(Q)`, and c the left unitor `λ_f : id_x ∗₀ f → f`. Then `depth_Y(c) = 2`, `Q↑Y` is the lax square of §2.3, and the required 3-cell has type

```
L := (λ_{f⁻} ∗₀ y↑) ∗₁ f↑      →      R := (id_x ∗₀ f)↑ ∗₁ (x↑ ∗₀ λ_{f⁺}).
```

Here `(id_x ∗₀ f)↑` is the depth-1 term of BMOSV Example 1.2, with `(id_x)↑ = ι : id_{x⁻} ∗₀ x↑ → x↑ ∗₀ id_{x⁺}` a coherence over the disc `(x⁻, x⁺, x↑)`. It is a composite

```
α₁ ∗₁ W ∗₁ α₂ ∗₁ (ι ∗₀ f⁺) ∗₁ α₃
```

of associators α₁, α₂, α₃ and a whiskering W of `id_{x⁻}` with `f↑`.

Write `p := f⁻ ∗₀ y↑` and `q := x↑ ∗₀ f⁺`, so that `f↑ : p → q`.

1. **Peel the unitor off the whiskering.** Over the chain `x⁻ → y⁻ → y⁺`, (F1) gives a 3-cell
   `λ_{f⁻} ∗₀ y↑  →  α_{id,f⁻,y↑} ∗₁ λ_p`.
   Whiskering it with f↑, and reassociating the vertical composite (F1 over a vertical chain of 2-cells, substituted), gives
   `L → α ∗₁ (λ_p ∗₁ f↑)`.
2. **Slide f↑ through the unitor.** (F2) for λ over `(a, b, g)` with `{g}`, substituted at `g↑ ↦ f↑`, gives
   `λ_p ∗₁ f↑  →  W' ∗₁ λ_q`,
   where W' is a whiskering of `id_{x⁻}` with f↑.
3. **Compare what remains on the + side.** The 2-cells λ_q and `α₂ ∗₁ (ι ∗₀ f⁺) ∗₁ α₃ ∗₁ (x↑ ∗₀ λ_{f⁺})` are parallel and full over the chain `x⁻ → x⁺ → y⁺`, which is a pasting context. (F1) connects them.
4. **Match the whiskerings.** W and W' are parallel full terms over the disc-with-unit pasting context, so (F1) connects them.

Composing these cells, with reassociations from (F1), gives `L → R`. ∎

*Machine-checked (2026-11-18):* `src/CaTTExp/Free/LeftUnitorDepth2.agda` builds this 3-cell, with (id_x ∗₀ f)↑ given by an explicit depth-1 naturality term for binary composition substituted with ι, and the certified checker accepts it with type `L → R`.

**Why this works.** After f↑ is slid out of the way, every remaining comparison involves 2-cells between composites along a single path through the square. On a 1-dimensional Q, every such path is a chain, hence a pasting context, so (F1) applies.

### Proposed induction

The same pattern suggests an induction on `dim Q`.

1. Slide the top-dimensional cylinder cells through the coherences, using (F2).
2. The residual comparisons then live over cylinders on the *boundary* of Q, which has lower dimension.

For 1-dimensional Q the residuals are chains, so they are handled by (F1), as in §6 (partial progress). For `dim Q = 2`, the residuals live over cylinders on 1-dimensional pasting contexts. Those are lax ladders, not pasting contexts, so the residuals should themselves be instances of the conjecture one dimension down.

What is missing is a precise *relative* form of the conjecture: a statement about cells between composites in `Q↑Y` that are not of the exact form `a_c → b_c`, strong enough to serve as the induction hypothesis.

## 7. Smallest open instances

The left unitor at depth 2 is settled in §6 (partial progress). **Cases 1 and 2 below are now settled** by the relative ladder theorem in the researcher response (verified 2026-11-18). Case 3 is the smallest open instance; also open are arbitrary up-closed Y on a chain.

1. **The associator** `(f ∗₀ g) ∗₀ h → f ∗₀ (g ∗₀ h)` over three composable arrows, with Y = all variables. BMOSV Example 1.3 treats it for `Y = {f, g, h}` only; including the objects raises the depth to 2. The sliding argument of §6 (partial progress) should apply, since Q is 1-dimensional, but it has not been checked in detail. Three cylinder cells must be slid, and one must verify that each residual comparison lies along a single path.
2. **All 2-dimensional coherences over 1-dimensional Q**, with Y = all variables. This is the general case of the §6 (partial progress) argument.
3. **First case with dim Q = 2.** For example, Q the 2-disc `(x, y, f, g, α : f ⇒ g)`, Y = all variables, and c the right unitor for vertical composition `α ∗₁ id_g → α`, a 3-cell of depth 3. This is where the induction of §6 (proposed induction) is needed.

## 8. Relation to molecular coherences

Write `P ⊗ D¹` for `P↑Var(P)`. It presents the strict Gray tensor of P with the 1-globe (§5), which is a molecule in Hadzihasanovic's sense (*Combinatorics of higher-categorical diagrams*).

- For a *coherence* constructor c, both `a_c` and `b_c` should be full terms over `P ⊗ D¹`, with the same boundary; this still needs a support theorem for the boundary lifts. For a *composition* constructor it is false: for c = f ∗₀ g, `a_c` and `b_c` are 1-terms that miss f↑ and g↑. There the argument must use fullness on the source and target boundary molecules and build a composite. (Corrected 2026-11-18.)
- Suppose the coherence rule were extended from pasting contexts to frame-acyclic molecules with the same two side conditions, and that this extension were conservative over CaTT (every new term equivalent to a CaTT term). Then `a_c → b_c` would be inhabited by a molecular coherence, hence by a CaTT term. So Conjecture N for `Y = Var(P)` would follow, at least when `P ⊗ D¹` is frame-acyclic. All molecules of dimension ≤ 3 are frame-acyclic (Chanavat, arXiv 2603.22242).
- The sliding argument of §6 is an instance of the layering technique such a conservativity proof would use: reorder the top-dimensional atoms, and compare what lies between them along 1-dimensional paths.

Conjecture N is therefore a special case of molecular conservativity, but a targeted one. It needs only the molecules `P ⊗ D¹` (and partial cylinders), and only cells between the two specific composites `a_c` and `b_c`.

## 9. Variations worth stating

- **Orientation.** The definitions above fix one orientation (cylinders of targets after `t⁻`). The other orientations are obtained by taking opposites in chosen dimensions (Benjamin–Markakis, arXiv 2402.01611). They should behave the same way.
- **Iterated cylinders.** If Conjecture N holds for all contexts (§3, Consequence), then applying it to `Γ↑X` with the up-closed set `{x↑ : x ∈ X}` produces `Γ⊗D²`: two parallel cylinders and a filler between them. Iterating gives `Γ ⊗ Dᵏ` for all k.

## Literature status (searched 2026-11-18)

**Status (updated 2026-11-18 after a verified researcher response): open in general. Every 2-dimensional coherence over a fully selected chain is now settled (§7 cases 1–2). Open: the 3-dimensional unitor over the 2-disc, arbitrary up-closed Y on a chain, and arbitrary depth.** The literature search found: the depth ≤ 1 case (BMOSV) was the published frontier. The latest version of BMOSV ([arXiv 2501.11620v3](https://arxiv.org/abs/2501.11620)) says explicitly that "the higher-depth cases ... are beyond our present work". No follow-up was found.**

Related results:
- **Molecular conservativity (§8).** This is problem G of `gray-contexts-in-catt.md`, also open. That file's §6 (Mikhail's Gray rules, formerly `gray-contexts-steiner.md`) asks for the same contexts `Γ ⊗ D¹`, and higher `Γ ⊗ Dⁿ`, through free-variable side conditions instead of explicit naturality terms.
- **The semantic analogue in (∞,ω)-categories is known.** For a pasting context P, the strict Gray cylinder `P ⊗ D¹` is free as an (∞,ω)-category, and it is Campion's Gray tensor (Campion, [arXiv 2311.00205](https://arxiv.org/abs/2311.00205), Example 3.2 and Cor. 3.5; Chanavat, [arXiv 2603.22242](https://arxiv.org/abs/2603.22242), Thm 3.29). So in (∞,ω)-categorical semantics every cell c has a naturality cell `c ⊗ D¹` between the two composites `a_c` and `b_c`, at every depth. This does not transfer to CaTT's models, Grothendieck–Maltsiniotis weak ω-categories, because no comparison between those and (∞,ω)-categories is known.
- **The groupoidal case.** In homotopy type theory, naturality of any operation along paths holds by path induction. BMOSV's exports to HoTT make this concrete only up to depth 1.

## 2. Proof

### 2.1. Comparisons along one directed path

For a directed path \(w\), let \(C(w)\) be its 1-dimensional pasting context.

Every 1-term over \(C(w)\) with the endpoints of the entire path has full typed support in \(C(w)\). To see this directly from the syntax:

- A 1-dimensional constructor with a 0-dimensional arity supplies an identity.
- A 1-dimensional constructor with a 1-dimensional arity composes successive 1-terms.
- An arity of dimension greater than 1 cannot satisfy either fullness condition for a 1-dimensional term.

Thus such a term traverses every generating edge of \(w\), in order.

Consequently, for any two such 1-terms \(a,b\), define
\[
\kappa_w(a,b)
=
\operatorname{coh}_{C(w),\,a\to b}[\mathrm{id}].

### 4.5. A directed cylinder does not by itself give a path object

The constant-arrow map \(C\to[2]\) misses the middle functor up to isomorphism, so it is not an equivalence.
